# 웹 요청 대상 탐지의 FPAD 독립 평가

2026년 11월 25일 · `extra` · 로컬 CPU 평가

## 평가 범위

NDSS 2026 WebSpotter 저자가 공개한 FPAD와 FPAD-OOD의 테스트 파일 전체를 사용했다. 발행자 커밋은 `5cdebaa9738b94bccef22c6d88092e2f142162a2`다. 저장소와 브랜치의 개발 기록에서 이 자료를 튜닝에 사용한 흔적을 찾지 못했다. 발행자 학습 파일은 사용하지 않았고 이전에 고정된 Coraza 3.8.1·CRS 4.25.0 바이너리를 그대로 검사에 사용했다. [발행자 저장소](https://github.com/Sec-AI-research/WebSpotter) · [NDSS 논문, VII.A와 Artifact Appendix](https://www.ndss-symposium.org/wp-content/uploads/2026-s1029-paper.pdf)

검사 입력은 메서드와 요청 대상이다. 입력에는 본문, 발행자 라벨, 악성 부분의 위치 주석, 원본에 없는 요청 헤더·응답·인증 상태를 제공하지 않았다. 데이터로 저장된 요청을 로컬에서 읽어 검사했으며 외부나 로컬 웹 서버로 요청을 재생하지 않았다. 검사기와 같은 계열의 기존 요청 대상 신호가 맞는 경우도 별도로 집계했다. 원시 자료는 로컬 `runtime/`에 두었다.

관측·CRS 판정·우선 검토 판정을 먼저 봉인한 뒤 발행자 라벨을 대조했다. 첫 채점에서 원본이 0~4 정수 라벨임을 확인해 0은 정상, 1~4는 위협으로 읽도록 채점기를 고쳤다. 재실행에서 같은 FPAD-OOD 판정 파일을 얻었으며, 두 최종 자료의 관측·CRS·우선 검토 파일 지문을 다시 확인했다. FPAD에는 정상 5,588건과 위협 10,609건이 있고 FPAD-OOD의 21,180건은 모두 위협이다. 반복 요청도 원본 행 단위로 포함했다.

## 미탐과 본문

| 위협 요청의 본문 | FPAD 탐지 / 위협 | FPAD-OOD 탐지 / 위협 |
| --- | ---: | ---: |
| 비어 있음 | 3,703 / 5,517 (67.12%) | 7,640 / 11,029 (69.27%) |
| 값 있음 | 650 / 5,092 (12.77%) | 1,197 / 10,151 (11.79%) |

FPAD에서 미탐 6,256건 중 4,442건, FPAD-OOD에서 미탐 12,343건 중 8,954건이 본문을 포함했다. 본문은 예측에 사용하지 않았으므로 실제 본문에 위협 신호가 있는지를 이 집계에서 확인할 수는 없다. FPAD의 정상·위협 사이에 메서드와 요청 대상이 모두 정확히 같은 행은 0건이었으므로, 현재 실험으로는 입력이 완전히 같아 생긴 분류 한계를 입증하지 못했다. 요청 형식과 본문을 실제로 관측할 수 있는 자료에서 요청 대상 단독 판정과 요청 대상·본문 판정을 비교할 필요가 있다.

## 재현과 증적

고정 소스와 앞선 실험에서 사용한 로컬 CRS 바이너리가 필요하다. 새 출력 경로를 지정한다. 도구는 파일 지문이 달라지면 검사 또는 채점을 중단한다.

```powershell
python -m scripts.evaluate_public_fpad_crs prepare <새-출력> <발행자-test.jsonl> <fpad|fpad-ood>
python -m scripts.evaluate_public_fpad_crs capture <새-출력> <고정-CRS-실행파일>
Get-FileHash <새-출력>/seal.json -Algorithm SHA256
python -m scripts.evaluate_public_fpad_crs score <새-출력> <발행자-test.jsonl> <seal-SHA256>
```

관련 로컬 회귀 152개와 Ruff를 통과했다. AWS와 유료 API 호출은 0회였다. 제품 탐지 및 권한 경로 수정은 이번 평가에 포함하지 않았다. [FPAD 집계](infrastructure-results/public-fpad-target-crs-20261125.json) · [FPAD-OOD 집계](infrastructure-results/public-fpad-ood-target-crs-20261125.json)
