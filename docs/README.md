# 개발 주차별 산출물

이 문서는 수행계획서의 개발 구간과 `aitest` 브랜치의 실제 구현을 연결한 색인이다. 기능을 계획보다 앞당겨 구현했으므로 **기능 진척 주차**와 실제 학사 일정은 구분해서 해석한다.

## 현재 진척

| 계획 구간 | 계획 목표 | 구현 상태 | 근거 |
|---|---|---|---|
| 3~4주차 | 위협 시나리오·아키텍처 설계 | 완료 | [3주차](week03/README.md), [4주차](week04/README.md) |
| 5~6주차 | 합성 로그·프롬프트 초안 | 완료 | [5주차](week05/README.md), [6주차](week06/README.md) |
| 7~8주차 | 1차 프로토타입 구현 | 완료 | [7주차](week07/README.md), [8주차](week08/README.md) |
| 9~10주차 | 자동 대응 기능 개발 | 완료 | [9주차](week09/README.md), [10주차](week10/README.md) |
| 11~12주차 | 통합 API·대시보드 | 완료 | [11주차](week11/README.md), [12주차](week12/README.md) |
| 13~14주차 | 성능 검증·고도화 | 완료 | [13주차](week13/README.md), [14주차](week14/README.md) |
| 15~16주차 | 최종 보고서·발표 | 미착수 | 최종 양식, 발표자료, 멘토 피드백 반영 필요 |

## 현재 MVP 기준선

- 버전: `0.6.0`
- 합성 시나리오: 정상 3건, 위협 5건
- 분석기: 규칙 기반, OpenAI 구조화 출력, 선택형 하이브리드
- 대응 방식: 실제 실행 없는 정책 미리보기
- 운영 흐름: 검토 대기, 조사 중, 해결 완료, 오탐 처리, 재검토
- 저장소: 로컬 JSONL 또는 AWS DynamoDB
- 검증: pytest 49건, 40건 반복 성능 평가, 비용 없는 Docker 종단 테스트, 브라우저 UI 검증

## 안전 범위

MVP는 실제 계정 차단, 권한 변경, 세션 격리를 실행하지 않는다. 모든 대응은 `simulation` 모드의 미리보기이며 고위험·불확실·파괴적 조치는 사람 검토 대상으로 남긴다.
