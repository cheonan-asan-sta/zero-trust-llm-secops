# extra: 전체 제로트러스트 평가를 위한 추가 공개 자료 검토

2026-11-12 · 카탈로그 조사 후 GRAAI 압축/CSV 검증과 첫128개 개발 기록의 구조를 확인했다.
RBA 본문은 미수집·미열람이다. ZTA-RAD의 후속 제한 조사 범위는 아래 v24 기록을 따른다. **아래 자료는 아직 목표 충족 근거가 아니다.**
원시 AIT 후보가 좋아졌다는 이유로 기존 여섯 탐지 영역의95% 목표를 축소하지 않는다.

후속 [v23 CloudTrail 학습 전용 감사](extra-flat-tree-and-cloud.md)에서 추가20,711건의 실제 MFA/역할 관측을
확인했다. 테스트 본문은 미수집이며 신뢰/정책 결측·라이선스 미선정·학습 전용 범위를 보존한다.
MFA 미사용을 실패로 바꾸거나 원래 여섯 영역의 최종 평가로 치환하지 않는다.

[v24 정보/라벨 근거 검토](extra-cloud-information-and-labels.md)에서 CloudTrail 단일 관측의 학습 자료 F1 상한93.76%와
두 학습 파일의 principal/역할 공통성을 확인했다. ZTA-RAD는 전문가 CSV 첫128개와 노트북 코드만 조사했으며
집계 위험 규칙과 결측 때문에 기기 건강·실제 권한 위반의 독립 정답으로 채택하지 않았다.

## AIT만으로 현재 증명할 수 없는 것

| 기존 영역 | 현재 AIT 개발 관측 | 아직 부족한 근거 |
|---|---|---|
| 인증 위협 | 인증/접속 로그 | 실제 계정 활성·MFA 상태·정상 업무 맥락 |
| 기기 신뢰 | 호스트/센서 관측 일부 | 권위 있는 관리 여부·EDR 상태·정상/손상 기기 정답 |
| 권한 오용 | su·sudo·감사 명령 | 자원 소유자가 정한 역할/행위 정책과 사용자 권한 맵 |
| 측면 이동 | 스캔·웹 요청·접속 | 보호 자원의 식별/경계·인가 상태·연속된 주체 연결 |
| 유출 | DNS 유출 관련 행 | 자원 민감도·승인된 업무/전송 범위·다른 유출 형태 |
| 원격 접속 | VPN 단계 | 정상 TLS 접속과 탈취 자격 증명 접속을 구분할 별도 신뢰 맥락 |

공격 캠페인에 속한 정상 프로토콜 단계도 발행자는 공격 관련으로 라벨링할 수 있다.
이 정답은 보존하되 곧바로 “그 행 자체가 권한 위반”이나 “그 시점에 차단 가능”으로 해석하지 않는다.
없는 역할·기기·승인을 만들어 입력을 완성하지 않으며 지원하지 못하는 영역을 평가에서 조용히 빼지 않는다.

각 영역의 정상/위협 지지, 라벨 출처, 관측 가능한 근거와 결측을 먼저 검토한다.
분할 전에 본 사례는 개발 자료로 기록하며 새 독립 평가로 재포장하지 않는다.

## GRAAI 카탈로그 고정

공개 GitHub API와 발행자 README/LICENSE를 읽었고, 고정 데이터 압축/CSV만 후속 검증했다.

  설치된7-Zip으로 인덱스를 확인하고 이름이 고정된 단일 일반 CSV만 stdout으로 스트리밍했다.

카탈로그 원자료는 `runtime/f1/contextual-source-catalog-20261112/`에 고정 커밋/파일 메타데이터와

26개 비JSON/미해석 메시지를 확인했다. 정답/입력·연결성 분할을 추가 검토하기 전 최종 평가로 쓰지 않는다.
`Suspicious`와 파생 위험/결정 플래그, 출처/호스트 이름·시간대 암기를 추론 특징으로 쓰지 않는다.
