# 감사 의도 모델의 추가 개발 학습 — v107 진행 기록

2026-11-16 · 채희주 담당 · 무료 로컬 · 전체 목표 active · push/새 CI/병합 보류

[v106](extra-audit-intent-context.md)은 웹 감사 오탐6건을 제거했지만, 운영 로그 조회 문맥의 지지는2건뿐이어서 남은15건을 낮추지 않았다. 최소 지지를5→2로 낮추거나 Fox의 남은 사례를 학습에 넣는 방식 대신, 원래 개발 자료로 제안한 Shaw·Wheeler를 추가 수집한다. 두 자료는 **명시적인 학습용**이며 새 독립 최종 평가로 부르지 않는다.

## 사전에 고정한 계약

[추가 학습 프로토콜](../infra/f1-lab/audit-intent-training-extension.json)에 게시자 버전·파일 크기·MD5·기간·역할·전체 파일 선택·최소 지지·공격 관측 veto를 고정했다. 게시자 [AIT LDS 2.1](https://zenodo.org/records/19483937)의 파일 목록과 미러 라벨 계약을 따른다. 압축 전체를 게시자 MD5로 확인하고 로컬 SHA를 계산한 뒤, 정확히 짝지어진 audit/auth 로그만 읽는다. MD5와 로컬 SHA는 게시자의 디지털 서명이나 원격 증명이 아니다.

R/S/Wilson은 기존 학습 자료이고 Shaw/Wheeler를 추가한다. Wilson을 v106에서 학습에 소비했다는 노출 변경을 유지하며 예전 독립 전이 역할을 복구하지 않는다. Fox·Wardbeck·이미 관측한 Harrison은 이번 학습에 넣지 않는다. 기존 Wardbeck 보정 역할도 유지한다. 예전 전체 분할 제안은 당시 기록으로 보존한다.

## 수집과 판정 연결

[수집기](../scripts/prepare_intent_training_source.py)는 메타데이터에서 모든 정확한 gather↔labels audit/auth 쌍을 고정한다. 정답 파일이 없는 로그는 제외 사유를 남기며 정상으로 간주하지 않는다. 파일별64MiB/10만행·전체20만행 상한을 넘으면 실패한다. 호스트 facts의 UTC 설정, 원본·라벨·압축 지문, ZIP CRC, 물리 행 수와 라벨 행 번호를 검사한다. 압축 안의 코드나 명령을 실행하지 않는다. 원래 파일명을 로컬 출력 경로로 사용하지 않는다.

학습 계획과 입력 지문을 고정한 [학습기](../scripts/train_audit_intent.py)에 모든 선택 행을 제공한다. 모델의 최소 지지5와 학습 공격1건 veto는 그대로다. 새 정상 행을 원래 시험 분모에 더하지 않으며, 원래 시험의 정답·물리 행·임계값도 바꾸지 않는다. 학습에 정답을 사용하는 사실은 공개하고 예측에서는 학습 파라미터와 평가 정답을 구분한다.

[예측기](../scripts/run_audit_intent_review.py)의 선택 사항 `--with-risk-observations`는 v102 사건 순서와 v105 인증 위험을 먼저 적용하고, 명시적 위험을 보존한 뒤 학습한 감사 의도를 적용한다. 추가 전이 비교에서도 같은 위험 판정 순서를 적용할 수 있다. 기본 운영 탐지기를 바꾸지는 않는다.

종료한 SSH 세션의 이전 lifecycle을 재사용하지 않으며, 미상 시각에서는 연결 문맥을 비운다. gshadow/opasswd 조회 뒤의 위험도 성공한 로그인으로 지우지 않는다. 검토와 자동 집행 금지 경계를 유지한다.

## 현재 검증 상태

소스 commit `8fff6c5869e766c1901cabc902ebc9562ce48701`에서 Linux 관련436건과 Ruff를 통과했다. 잘못된 학습 역할·UTC·라벨 범위·원본 변조·기존 출력 덮어쓰기 거부, 정답 없는 로그의 정상 추정 금지, 기존 인증 위험 우선 처리와 SSH 문맥 폐기를 포함한다. 기능 소스 SHA는 `7c840bf3dfdffbf3b5f6ace9ac0d24d01e9f3a63e2026ded280bfa7aa8b1d2b3`이다. 소유 컨테이너 제거를 확인했다.

추가 자료의 무결성 확인·정확한 파일 쌍 준비·모델 고정 후, 기존1,681,815행과 별도8,908행을 이전 결과와 비교한다. 기존 TP 손실이나 새 FP가 생기면 그 후보를 채택하지 않는다. **새 성능 수치는 아직 확정 전이며 최신 확정 수치는 v106이다.**

공유 감사와 VPN의 근거 부족·원래6개 보안 영역의 독립 인수는 별도로 남아 있다. 위 기능 시험 통과를 전체 목표 달성이나 새 독립 F1로 합산하지 않는다. 비용이 나는 API/AWS·새 CI·push·병합·장기 soak는 실행하지 않는다.
