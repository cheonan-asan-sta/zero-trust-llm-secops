## CloudTrail이 추가로 제공하는 관측과 제공하지 않는 신뢰

발행자 [ArielCyber/cloud_log_sampling 고정 README](https://github.com/ArielCyber/cloud_log_sampling/blob/18d3f248f4def592f4e86152c3fcb54506fbcbf6/README.md)는
제어된 AWS 정상 업무·공격 실행으로 수집한 CloudTrail, 학습/테스트 분리와 `should_sample` 라벨 의미를 설명한다.
우리 AWS 계정을 사용한 실행이 아니다. 본문 수집 전에 [학습 전용 계약](../infra/f1-lab/cloud-intake-protocol.json)을 고정했다.

- 고정 커밋: `18d3f248f4def592f4e86152c3fcb54506fbcbf6`.
- `TrainOn/base_a.zip`와 `TrainOn/train_labeled_a.zip`만 받았다. 정확한 크기·Git blob SHA1·ZIP CRC를 검사하고
  각 원본 JSON의 SHA256을 전후 대조했다. 해시는 발행자 서명을 뜻하지 않는다.
- `TestOn/labeled_cloudtrail_a.zip`은 다운로드하지 않았다. README에 있는 예시와 집계는 이미 확인한 상태다.
- 고정 트리에 LICENSE/COPYING/TERMS 파일이 없고 API license는 null이었다. 공개 자료의 읽기 전용 구조 연구만 진행했으며
  제품 채택·재배포는 선택하지 않았다. 내려받은 코드는 실행하지 않았다.

| 학습 자료 | 행 수 | 정상 | 공격 | 라벨 미확정 | 관측 오류 | MFA 사용 | MFA 미사용 | MFA 미확정 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| base | 16,495 | 16,495 | 0 | 0 | 0 | 234 | 14,341 | 1,920 |
| mixed train | 4,216 | 3,675 | 541 | 0 | 0 | 366 | 900 | 2,950 |

`should_sample`은 이 출처에서만 발행자가 공격/정상으로 정의한 필드다. 일반 로그 보존 선택을 공격 라벨로 추측하지 않는다.
명시 boolean과 `attack_name`의 일관성을 확인하고 입력 관측/정답을 별도 파일에 썼다.
관측 해석이 실패해도 알려진 정답 행을 평가 모집단에서 삭제하지 않는다.
없거나 모순된 라벨은 미확정으로 남기는 경로도 시험했다. 원본에는 필드를 삽입하지 않는다.

`mfaAuthenticated=false`는 세션에서 MFA가 사용되지 않았다는 관측이다. 정상 서비스의 AssumedRole에도 존재한다.
MFA 실패 횟수·계정 비활성·기기 손상으로 변환하지 않는다. 세션 발급 역할이 있어도
자원 소유자의 허용 역할/행위 정책이 있는 것은 아니다. 계정 활성·관리 기기·기기 건강·자원 요구 역할·업무 승인·MFA 실패·전송량은
모두 미확정으로 보존한다. API 이름과 역사적 세션 나이는 관측 특징이지만 현재 신뢰를 암호학적으로 검증한 것은 아니다.
응답 자격 증명·임의 요청 본문은 허용 목록 밖이며 복사하지 않는다. 실제 principal/ARN/IP는 연결용 해시 참조로만 남긴다.

이번 단계는 20,711건의 **학습 자료 감사**이며 CloudTrail 분류 모델 학습·최종 테스트는 수행하지 않았다.
학습/테스트 사이 주체·역할·자원·요청 양식 중복과 라벨의 정책 의미도 아직 인증하지 않았다.
CloudTrail 라벨을 기존 여섯 영역의 정책 위반 정답으로 일괄 매핑하지 않는다.
