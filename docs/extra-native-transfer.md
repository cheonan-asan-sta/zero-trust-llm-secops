## 모델을 바꾸지 않고 확인한 것

russellmitchell에서 적합한 v20 트리와 임계값0.5를 고정하고 santos에 적용했다.
모델 SHA256은 `2d01d0ed310223ff51e185d53a51b2fc183226a4ad8f7593ec8ab5404f5419b1`이다.
`evaluate_native_tree.py`는 재학습 함수 없이 고정 JSON만 검증해 읽고, 평가 전후 모델 상태가 같은지 확인한다.
평가 정답을 뒤집어도 예측/모델이 바뀌지 않는 시험과 평가 중 학습 함수를 호출하지 않는 시험을 추가했다.

`native_tree.load_frozen`은 외부 SHA·크기·특징 계약·노드 경계·클래스 가중치·확률/건수·분할 이득을 확인한다.
Python 모델 코드나 pickle을 불러오지 않는다. 잘못된/누락 관측의 정답 행은 분모에 남겨 오분류로 집계한다.
최초 집중 시험7통과/1실패는 범주 변조 fixture가 boolean 자식3개를 만들어 먼저 분할 수 한도에 걸린 경우다.
기존 가드를 완화하지 않고 자식 하나를 잘못된 범주로 교체하도록 fixture를 고쳤으며 최초 XML도 남겼다.
