## 구현과 선정 근거

`OrderedAuditReview`는 기존 `AuditReview`를 보존하면서 같은 물리 원본의 SHA를 매 관측에 확인한다. 기존 web-service su → account transition 관계, 보고 PID·계정 연결·원래5초 창이 유지된 LOGIN만 대상으로 한다. 시간이 같아도 **원본 timestamp가 같고 audit serial이 엄격히 증가한 별도 사건**이면 추가 위험 관측을 만들 수 있다. 같은 serial의 여러 기록은 새 선행 사건으로 계산하지 않는다. 파일 간/동시각 auth seed 연결을 확장하거나 미래 행을 선행 근거로 가져오지 않는다.

일련번호/시각 역행·잘못된 prefix/시각 결속은 해당 원본의 추가 순서 기능을 중단한다. PID 변경·종료·계정 변경·unset 식별자·잘못된 source pin은 새 연결을 허용하지 않는다. 기존 strictly-later 판정은 계속 보존한다. 새 기능은 명시적인 `review_factory`를 전달하는 오프라인 예측 CLI에서만 사용하며 기존 실행기의 기본 동작을 변경하지 않는다.

Linux Audit의 공식 설명은 같은 timestamp/serial을 같은 사건의 여러 기록으로 묶고, 같은 밀리초의 사건을 serial로 구분한다. [audit-userspace EVENTS](https://github.com/linux-audit/audit-userspace#events). 커널의 serial 생성/tuple 사용도 확인했다. [Linux v6.6.37 audit.c](https://kernel.googlesource.com/pub/scm/linux/kernel/git/stable/linux-stable.git/+/refs/tags/v6.6.37/kernel/audit.c). 이를 근거로 같은 소스 안의 관측 순서를 보강한 것이며, 암호학적인 인과/실제 사람 인증·PID 생애·업무 승인을 증명했다는 뜻은 아니다. 재부팅·rotation/혼합 소스·누락·실시간 수집의 인수는 별도다.

원래 모델/임계값/라벨은 유지했고, source ID·계정명·공격 일정·case ID를 정상/위협 예외 특징으로 넣지 않았다. `refine`은 기존 경보를 보존하며 추가 위험 관측만 반영한다. 자동 집행·권한 부여·세션 회수·앱/대시보드 변경은 없다.

## 묶음 테스트·평가 절차

- Windows의 새 순서/기존 감사/로컬 게이트95건, Linux 묶음339건을 통과했다. Windows95는 Linux 묶음의 부분집합이며 합산하지 않는다. 이 검사 수가 탐지 정밀도/재현율을 뜻하지 않는다.
- Linux Docker는 network none·UID10001·cap drop·NNP·read-only root·2CPU/2GiB다. 원본과 baseline 예측, preparation 메타데이터만 제공하고 정답 파일/집계 정답 비율은 넣지 않았다. source.tar의 고정 코드로 예측한 뒤 모든 지문을 봉인했다.
- 소유 컨테이너를 제거한 뒤 원래 정답을 열어 순서·case ID·전 모집단·출처별 baseline 행렬을 대조했다. 입력/소스 지문은 전후 동일했다. 라벨 재열람은 이미 관측한 개발 채점으로 기록했다.
- 소스 SHA `17e0d54367e7fa498d4a5fdeb3db5bfa170682d538d86dc05d2114a758d40c39`, 코드 commit `678d7802e3a685502f389959cf22760f025db8d9`다. 원본/정답/큰 예측은 ignored runtime에 보관한다. 이 단계에서 전체 pytest를 다시 실행했다고 주장하지 않는다.
- 첫 포장 실행은 Git executable mode를 놓쳐 Ruff EXE001에서 중단됐다. 예측 전 실패이며 소유 자원을 정리했다. Git 모드를 보존한 새 아카이브로 묶음을 다시 실행했으며 검사 규칙을 비활성화하지 않았다. 추가 순서 중단을 시험하면서 기존 later-time 판정도 중단될 것이라고 잘못 기대한3개 테스트는 기존 판정 보존을 검증하도록 바로잡고, malformed 입력 후 새 equal-time 연결 차단 검사를 추가했다.
