# 공개 Apache 오탐 후속 검토

2026-11-23 · `extra`의 이전 [Apache 공개 평가](extra-public-priority-evaluation-20261123.md) 예측을 기준으로 진행했다. 제품 코드는 `85eeb46` 스냅샷이며 발행자 라벨·원본·평가 행을 유지했다. 실행은 무료 로컬에서 진행했다.

## 기존 POST 보정의 전이 결과

이전 개발에서 동결한 [POST 보정](extra-post-refinement-development.md)을 Apache 자료에 처음 적용했다. HTTP 응답과 기존 보안 관측을 사용하고, 그 보정의 모델·임계값은 다시 학습하거나 조정하지 않았다. 기존 경보를 재현한 뒤 후보 예측을 SHA-256으로 고정했다. 채점에서는 앞선 발행자 규칙을 그대로 적용했다. 발행자가 붙인 패턴 기반 라벨과 대조한 지표다. [발행자 자료](https://zenodo.org/records/20001206)

| 같은 로그 213,205행 | 정밀도 | 재현율 | F1 | 오탐률 | TP / FP / FN / TN |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 공개 평가 | 1.26% | 80.92% | 2.49% | 16.23% | 441 / 34,506 / 104 / 178,154 |
| 기존 POST 보정 추가 | 1.78% | 80.92% | 3.48% | 11.45% | 441 / 24,357 / 104 / 188,303 |

오탐은 10,149건 감소했고, 새 오탐과 전체 기존 탐지 손실은 각각 0건이다. **POST 2xx 17,898행에는 위협 라벨이 한 건도 없었다.** 이 집단의 경보 10,151건 중 10,149건이 해소됐지만, 같은 집단의 위협 탐지 보존은 이 자료에서 측정할 수 없다. 전체 목표는 미달이며 운영 판정 적용은 보류한다.

## 리다이렉트와 필요한 근거

| 집단 | 전체 행 | 발행자 양성 | 기존 탐지 / 미탐 | 기존 오탐 |
| --- | ---: | ---: | ---: | ---: |
| GET 3xx | 67,487 | 55 | 40 / 15 | 15,228 |
| HEAD 3xx | 30,374 | 4 | 4 / 0 | 4,287 |
| POST 2xx | 17,898 | 0 | 0 / 0 | 10,151 |

리다이렉트 상태만으로 경보를 일괄 해제하면 기존 탐지 44건을 잃는다. 세 집단의 기존 경보에서 발행자 라벨이 서로 다른 동일 특징 벡터는 관측되지 않았다. 이 결과에서 정상 리다이렉트를 확인할 수 있는 일반 규칙을 도출하지는 않았다. 각 접근 행의 응답 코드만으로 최종 이동 대상·애플리케이션의 인증·권한 처리 결과를 확인하기 어렵고, 성공한 POST를 판단하는 데 필요한 요청 본문과 승인 내역도 확인되지 않았다.

다음 인수에서는 정상과 위협 POST가 모두 관측된 별도 자료를 확보해 동결된 보정의 탐지 손실 여부를 먼저 확인한다. 리다이렉트는 서버가 기록한 이동 대상·요청 식별자와 정책 결과를 연결할 수 있는 자료로 비교한다. 기존 [웹 요청 근거 계약](extra-web-verified-context.md)의 요청·세션 결속과 서명 검증을 재사용할 수 있다.

## 재현과 검증

아래 `original`에는 앞선 공개 평가의 `apache-verified` 디렉터리를 지정한다. `review`는 새 디렉터리다. 첫 실행이 예측을 저장한 뒤 두 번째 실행에 `review/seal.json` SHA-256을 넘기면 원본 순서와 봉인을 확인하고 채점한다.

```powershell
python -m scripts.audit_public_apache_review <archive> <original> <review>
python -m scripts.audit_public_apache_review <archive> <original> <review> --score-seal <SHA256>
```

웹 평가·판정·근거 관련 Windows 회귀 259개를 통과했다. [집계 결과와 예측 지문](infrastructure-results/public-apache-review-20261123.json)을 보관했다. 원본 로그·행별 산출물은 로컬 `runtime/public-priority-evaluation-20261123/review-v1`에 있다.
