# 8주차: 프로토타입 통합·하이브리드 분석·감사 저장

## 계획 목표

1차 프로토타입을 반복 실행 가능한 형태로 통합하고 비용, 지연, 실패 복구 조건을 보완한다.

## 구현 결과

- 규칙 분석의 신뢰도가 기준 이상이면 LLM 호출을 생략하는 하이브리드 분석기를 구현했다.
- 애매한 사건만 제한 시간 안에서 LLM으로 교차 검토한다.
- LLM 오류나 시간 초과 시 규칙 결과를 유지하면서 사람 검토 대상으로 전환한다.
- 두 분석 결과가 다르면 더 보수적인 위험도와 증거 집합을 선택한다.
- 단건 분석과 최대 20건의 배치 분석을 제공하고 동시 분석 수를 3건으로 제한했다.
- 로컬 JSONL 감사 기록을 재시작 시 복원하고, AWS 환경에서는 DynamoDB를 선택할 수 있게 했다.
- 규칙 모드 Docker 경로에는 OpenAI 키를 주입하지 않아 비용 없는 반복 검증이 가능하다.

## 실패 안전 원칙

| 상황 | 처리 |
|---|---|
| 규칙 신뢰도가 충분함 | 규칙 결과 즉시 반환 |
| 규칙 판단이 애매함 | LLM 교차 검토 시도 |
| LLM 시간 초과·오류 | 규칙 결과 유지, 사람 검토 전환 |
| 규칙·LLM 판단 불일치 | 더 높은 위험도 채택, 사람 검토 유지 |
