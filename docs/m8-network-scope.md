## 제안

이번 학술 MVP의 최종 인수는 **계정·세션에 결합된 신뢰 신호→정책 회수→보호 HTTP 접근 거부**에 둔다.
패킷 payload 수집·DPI·범용 IDS 탐지 엔진은 현재 인수에 추가하지 않는 안을 제안한다.
그 기능은 새 센서·데이터 보관·프라이버시·암호화 구간·정답셋을 별도로 검증해야 하므로,
기존 세션 판단/회수 근거를 완성하는 작업과 분리한다. 제외가 네트워크 위협 부재의 근거는 아니다.

네트워크만의 이상(횡적 이동·유출·세션에 연결되지 않은 트래픽)은 현재 관측만으로 보장하지 않는다.
IP 한 개나 경보 없음으로 신뢰를 높이거나 사용자/세션을 확정하지 않는다.
추가 요구가 생기면 payload 이전에 출처·수집시각·주체/기기·대상·방향·바이트량 등 필요한
메타데이터와 매핑 실패 시 처리부터 계약화하고 공개/합성 흐름으로 별도 평가한다.

## 채희주가 멘토에게 확인할 질문

“주제의 범위를 계정·세션의 지속 검증과 HTTP 자원 접근 집행으로 정하고,
현재 네트워크 메타데이터와 경보의 한계를 명시하면서 패킷 분석은 후속으로 두어도 되는가?”

확인 결과·멘토·일시는 아직 없다. 답변을 받은 뒤 최종 범위·제외 위험·필요한 추가 시험을 기록한다.
