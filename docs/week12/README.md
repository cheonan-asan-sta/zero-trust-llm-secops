# 12주차: 관제 대시보드·분석가 검토 흐름·MVP 완성

## 계획 목표

통합 API의 상태와 분석 결과를 시각화하고 5종 이상의 시나리오를 처음부터 끝까지 시연할 수 있는 MVP를 완성한다.

## 구현 결과

- 8개 시나리오 선택, 분석 실행, 위험 점수·판단 근거·정책 미리보기를 한 화면에 연결했다.
- 누적 분석, 고위험 건수, AI 교차분석 건수, 평균·P95 응답시간을 표시했다.
- 8개 기준 사례 반복 평가를 대시보드에서 실행하고 목표 통과 여부를 확인할 수 있게 했다.
- 사람 검토가 필요한 사건에 `PENDING`, `IN_REVIEW`, `RESOLVED`, `DISMISSED` 상태를 추가했다.
- 담당자와 검토 메모를 기록하고 해결·오탐 사건을 다시 조사 상태로 전환할 수 있게 했다.
- 검토 상태는 JSONL과 DynamoDB 감사 저장소에 보존되며, JSONL 업데이트는 같은 분석을 중복 집계하지 않는다.
- 최근 기록에서 사건을 다시 열고 처리 상태를 확인할 수 있게 했다.

## MVP 시연 흐름

1. 위협 시나리오 `ZT-S05`를 선택한다.
2. 합성 이벤트를 생성하고 규칙 분석과 정책 안전 검증을 수행한다.
3. `HIGH` 위험과 `HOLD_FOR_REVIEW` 대응 미리보기를 확인한다.
4. 담당자를 지정하고 사건을 `IN_REVIEW`로 전환한다.
5. 검토 메모를 남기고 `RESOLVED` 또는 `DISMISSED`로 처리한다.
6. 새로고침 후 기록을 다시 열어 상태와 메모가 보존됐는지 확인한다.

## 검증 결과

- pytest 47건 통과
- Ruff 코드 검사 통과
- JavaScript 문법 검사 통과
- 비용 없는 Docker 종단 테스트 통과
- Docker 종단 결과: `HIGH`, `HOLD_FOR_REVIEW`, 최종 검토 상태 `RESOLVED`
- 브라우저 수동 검증: 분석, 담당자 배정, 해결 처리, 새로고침 후 복원, 기록 다시 열기 통과
- Docker 실행 보안: 비루트 UID 10001, 읽기 전용 루트 파일시스템, capability 전체 제거, 추가 권한 획득 금지
