# DNS 분석 이력의 프로세스 경계 보완 — v61

2026-11-14. DNS 분석기가 질의 행에서만 resolver host/PID 변경을 확인하던 문제를 수정했다.
이제 응답·forwarded·시작 안내·해석할 수 없는 질의도 유효한 dnsmasq 접두부가 있으면
프로세스 변경을 확인하고 이전 이력과 같은 시각의 보류 질의를 모두 비운다.
시각을 해석할 수 없어도 확인한 프로세스 변경은 반영한다.
로그의 host/PID는 관측 경계일 뿐 신뢰된 사용자나 기기 인증 근거는 아니다.

## 기존 자료에서 확인한 영향

정답을 읽지 않고 원래 R/S/F DNS 전체와 v56 추출 특징을 순서대로 대조했다.
후속 판정 비교는 기존 v56 모델을 고정했고 다시 학습하지 않았다.
모든 후보 판정을 고정한 뒤 기존 라벨로 원래 혼동행렬의 변화를 확인했다.

|---|---:|---:|---:|

기존 v56 후보의 혼동행렬은 모두 같다. 미탐732건 감소와 새 오탐96건이라는
[이전 후보의 미채택 판단](extra-dns-context-development.md)은 바꾸지 않는다.
운영 탐지기·v52 기준선·Wilson 고정 평가도 변경하지 않았다.
이번 작업은 이력 계산의 정확성 보완이며 새 독립 성능 개선으로 보고하지 않는다.
