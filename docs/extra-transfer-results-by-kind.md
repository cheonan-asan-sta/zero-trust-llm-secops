위협 표본이28/11,090행으로 적어 정상 오탐168건이 경보의 대부분을 차지한다.
원래 v49에서는 웹 회전 파일이 선택되지 않았으므로 이 보고서의 access/error는 **자료 없음**이다.
나중에 관찰한 Harrison 웹 개발 결과를 같은 미관측 평가였던 것처럼 합치지 않는다.

## 구현과 판정 경계

- [요약 계산](../scripts/f1_lab/transfer_summary.py)은 원래 혼동행렬을 합산하고 지표를 다시 계산한다.
  파일 인덱스 중복·모집단 불일치·잘못된 종류·음수/비정수 건수·일치하지 않는 지표를 거부한다.
- [실행기](../scripts/summarize_transfer_results.py)는 호출자가 고정한 score/manifest SHA,
  후보 동결·원시 manifest·예측/정답 SHA를 확인하고 실제 예측을 재채점한다.
  저장된 집계와 다르면 보고서를 게시하지 않는다. 기존 출력도 덮어쓰지 않는다.
- 추론 실패는 기존 방식대로 FP/FN에 포함한다. 미상/없는 클래스를 정상으로 채우지 않는다.
- 정상 표본0이면 오탐률은 `null`, 위협 표본0이면 재현율·미탐률은 `null`이다.
  이 경우 해당 종류의 목표를 통과했다고 표시하지 않는다.
- 각 점 목표 충족 여부와 원래 목표 적합성을 분리한다. 모든 점 수치가 좋아도
  `goal_qualified=false`, 원래 여섯 영역 대응은 `unverified`로 남는다.
- 실제 독립 세션 수와 군집 구조를 확보하지 않았으므로 행을 독립 표본으로 가정한 신뢰구간을 만들지 않는다.

access/error/VPN은 수집 종류다. credential/device/privilege/lateral/exfiltration/remote의
원래 여섯 보안 영역을 이 세 종류로 축소한 것이 아니다. 공개 로그의 공격 관련 라벨도
그 자체로 기기 침해·자원 권한 위반을 모두 입증하지 않는다.
