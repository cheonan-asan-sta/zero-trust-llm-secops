# extra: 과거 관측 창과 동시 품질 목표의 가능성 검사

2026-11-12 · [v24 정보 부족 분석](extra-cloud-information-and-labels.md) 후속이다.
이미 관찰한 CloudTrail 학습 자료만 사용했고 **분류 모델 학습·독립 최종 평가를 수행하지 않았다.**
F1만95%를 넘기는 것으로 정밀도·재현율 각각95% 목표를 대체하지 않는다.

후속 [v26 원본 신원 근거 감사](extra-cloud-identity-and-rba.md)에서 AWSService3,107건의 원래 principal 연결 후보0을 확인했다.
누락을 임의 이력으로 채우지 않았고 RBA 보조 자료는 별도 계약 뒤 수집을 시작했다. 전체 검증·CSV 분석은 당시 미완료다.

## 무엇을 추가했나

[사전 계약](../infra/f1-lab/cloud-context-protocol.json)에 따라 동일 principal 참조의 엄격한 과거10/60초를 집계했다.
관측 호출·쓰기·오류 수, 알려진 API/자원 종류 수, 자원 근거 결측 수, 관측된 쓰기/오류 비율과
첫 관측 이후 경과를 고정 버킷으로 변환한다. 실제 이름·주체 ID·IP·절대시각·라벨은 특징이 아니다.
신원 참조는 이력 연결에만 쓰며 계정 활성·기기 건강·자원 소유 정책·업무 승인 근거를 만들지 않는다.

- 같은 시각의 모든 이벤트는 그 묶음의 특징 계산 후에 이력에 넣는다. 동률의 파일/행 순서로 과거를 만들지 않는다.
- 미래 이벤트를 추가해도 이전 특징은 바뀌지 않는다. 기존 행 순서와 case ID는 보존한다.
- 동일 이벤트 참조/관측 중복은 이력에 한 번만 반영하고 원본 행/정답은 모두 남긴다.
  뒤에 충돌하는 참조가 나와도 이미 계산한 과거를 바꾸지 않는다. 같은 시각의 상반된 참조는 임의 선택하지 않는다.
- principal/시각이 없으면 이력은 미확정이다. IP·발급 역할·전역 묶음으로 대체하지 않는다.
- `readOnly` 미확정은 쓰기로 채우지 않는다. 쓰기 비율은 값이 알려진 과거 행만 분모로 사용한다.
- 0회는 공개 자료에서 **관찰된**0회다. 샘플링·수집 중단 가능성이 있어 실제 활동 부재나 완전한 수집을 보증하지 않는다.
  요청된 설정과 실제 적용된 보안 상태, 과거 공개 로그와 현재 검증된 신뢰는 계속 구분한다.

20,711행 전부를 유지했다. 이력 연결 미확정3,134행, 동일 이벤트 중복9행, 관측 오류/참조 내용 충돌0이다.
양쪽 정답 sidecar SHA256은 v23/v24와 동일하다. 준비와 정답 사용 진단을 별도 단계로 실행하며
특징 함수에는 정답 sidecar/라벨이 전달되지 않는다. 기존 관측 파일을 덮어쓰지 않았다.

## 개선된 정보량과 아직 불가능한 동시 목표

서로 같은 특징 벡터가 가진 정상/공격 수로 이 **같은 학습 자료**의 결정적 분류 가능성을 계산했다.
이 계산은 정답을 쓰므로 모델 성능이나 새 평가 수치가 아니다. 기존 v24 결과도 보존한다.

| 진단 | 요청 관측까지 | 엄격한 과거 이력 추가 |
|---|---:|---:|
| 정확한 세션 나이 사용 시 고유 벡터 | 9,471 | 10,294 |
| 정상·공격 혼합 벡터 | 12 | 6 |
| 혼합 벡터의 행 수 | 1,429 | 1,377 |
| 가능한 최소 오분류 수 | 64 | 50 |
| 정답을 아는 이상적 최대 F1 | 93.7622% | 95.1550% |
| 정밀도95% 이상일 때 가능한 최대 재현율 | 90.5730% | 91.1275% |
| 재현율95% 이상일 때 가능한 최대 정밀도 | 40.4406% | 41.0841% |
| P/R/F1 각각95%·FPR5% 이하 동시 달성 가능 | 아니오 | 아니오 |

F1 최적점은 TP491·FP0·FN50으로 재현율90.76%다. F1 95.16%만 보고 목표를 달성했다고 할 수 없다.
정확한 세션 나이를 구간화하거나 빼도 과거 이력 프로필의 위 최대 F1·동시 목표 결론은 동일하다.
최소 오분류와 F1 최대, 특정 정밀도/재현율 목표는 각각 다른 목적함수다.

동시 목표 계산은 혼합 벡터의 가능한 양성 선택마다 TP별 최소 FP를 보존하는 동적 계획이다.
순수 공격 벡터는 양성, 순수 정상은 음성으로 둘 수 있다. 각 상태에서 P/R/F1/FPR 네 조건을 함께 검사한다.
작은 집합의 모든 결정 조합과 비교하는 시험으로 검산했다. 계산량 상한에 걸리면 미계산/미판정으로 반환하며 통과로 처리하지 않는다.
이 결과는 현재 관측·해당 학습 행 집합에만 해당한다. 새로운 관측·다른 모집단까지 불가능하다는 주장은 아니다.

서비스 호출을 원래 사용자·역할/세션에 연결할 독립 근거가 있는지 원본 필드를 검토하는 것이 다음 우선순위다.
서비스 이름·IP가 같다는 이유로 같은 사용자·물리 기기로 만들거나 공격 이름에서 연결 관계를 생성하지 않는다.
동일한 서비스 API의 정상 업무/공격 캠페인 구분과 자원 소유자의 실제 인가 위반 정답도 별개다.
