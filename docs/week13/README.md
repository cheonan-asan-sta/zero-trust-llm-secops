# 13주차: 반복 성능 측정·제한 병렬화

## 계획 목표

MVP의 반복 표본을 확대하고 처리 지연과 안정성을 정량적으로 측정한다.

## 구현 결과

- 평가 반복 범위를 시나리오당 최대 10회까지 확대했다.
- 평가 요청에서 동시 처리 수를 1~10 사이로 지정할 수 있게 했다.
- 세마포어 기반 제한 병렬화를 적용해 외부 분석기 호출이 무제한으로 증가하지 않게 했다.
- 평균뿐 아니라 P50, P95, P99 응답시간과 전체 소요시간, 초당 처리량을 계산한다.
- 기존 정확도·F1·JSON 유효율에 대응 정확도와 최대 오류율 목표를 추가했다.
- 대시보드의 기본 안정성 평가는 8개 시나리오를 5회씩, 총 40건 처리한다.

## 비용 없는 Docker 실측

2026년 9월 16일 로컬 Docker의 `rule` 모드에서 다음 결과를 확인했다.

| 항목 | 결과 |
|---|---:|
| 평가 사례 | 40건 |
| 위험도 정확도 | 100% |
| 대응 정확도 | 100% |
| 오류율 | 0% |
| P50 응답시간 | 0.01ms |
| P95 응답시간 | 0.02ms |
| 처리량 | 43,670.17건/초 |

처리량과 지연시간은 로컬 규칙 분석기의 순수 평가 구간 수치이며 실행 환경에 따라 달라진다. 네트워크를 사용하는 LLM 모드의 성능 수치로 해석하지 않는다.
