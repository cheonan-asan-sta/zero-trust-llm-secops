# 11주차: 통합 API·평가 자동화·배포 경로

## 계획 목표

FastAPI 엔드포인트, 테스트 결과 저장, 상태 조회와 반복 평가 기능을 하나의 서비스로 통합한다.

## 통합 API

| 기능 | 엔드포인트 |
|---|---|
| 상태·설정 확인 | `GET /health` |
| 시나리오 목록·상세 | `GET /scenarios`, `GET /scenarios/{scenario_id}` |
| 합성 이벤트 생성 | `POST /events/simulate` |
| 단건·배치 분석 | `POST /analysis`, `POST /analysis/batch` |
| 시나리오 조건 평가 | `POST /scenarios/evaluate` |
| 대응 미리보기 | `POST /response/preview` |
| 반복 성능 평가 | `POST /evaluation/run` |
| 메트릭·결과 조회 | `GET /metrics`, `GET /results` |

## 평가 지표

- 위험도 정확도와 대응 정확도
- 위협 탐지 precision, recall, F1
- 구조화 JSON 유효율
- 평균·P95 응답시간
- 목표 통과 여부

## 검증 결과

| 경로 | 표본 | 위험도 정확도 | 대응 정확도 | JSON 유효율 | 평균 응답 | P95 응답 |
|---|---:|---:|---:|---:|---:|---:|
| 로컬 규칙 분석 | 합성 8건, 1회 | 100% | 100% | 100% | 0.1ms 미만 | 약 0.04ms |
| AWS 직접 OpenAI 분석 | 합성 8건, 1회 | 75% | 62.5% | 100% | 약 4.2초 | 약 5.73초 |
| 하이브리드 분석 | 합성 기준 사례 | 100% | 100% | 100% | 측정 미기록 | 약 2.5초 이내 |

직접 OpenAI 분석은 정확도·JSON 목표는 통과했지만 수행계획서의 평균 응답 3초 목표는 통과하지 못했다. 자동 평가 API는 이보다 엄격한 P95 3초 기준을 사용한다. 하이브리드 경로는 규칙 결과를 우선 사용하고 제한 시간 후 안전하게 복구해 지연과 비용을 줄였다. 위 수치는 소규모 합성 표본의 기능 검증 결과이며 통계적 성능을 의미하지 않는다.

## 배포·저장 경로

- Lambda 컨테이너, ECR, DynamoDB 감사 테이블을 CloudFormation으로 정의했다.
- 대상 AWS 계정 `172585182454`를 배포 전 검증하도록 했다.
- 실제 배포와 기능 시험 후 과금 방지를 위해 생성한 프로젝트 리소스를 모두 삭제했다.
- 현재 반복 시험의 기본 경로는 OpenAI 키가 필요 없는 로컬 Docker 규칙 모드다.
