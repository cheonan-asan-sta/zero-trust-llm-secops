원본 앱·규칙·기존 정답은 그대로 보존한다. 기존 관찰 holdout360에서 원본은 P64.29%/

## 수집 구현과 현재 증거

`infra/f1-lab/public-assets.json`에 record/version/license/filename/bytes/발행자MD5를 고정한다.
수집 시작 시 외부에서 준 계약 SHA256과 발행자 API를 대조한다. 고정 공개 HTTPS GET만 사용한다.
발행자 MD5는 전자서명이 아니며 수집 후 SHA256도 발행자 서명이 아닌 로컬 고정 지문이다.

`scripts/f1_lab/public_sources.py`는 크기·시간·재시도 한도와 정확한 Content-Range를 검증한다.
중단된 구간은 실패 기록과 함께 보존하고 새 디렉터리로 이어받는다. 전체 크기/MD5가 일치해야
`.part`를 최종 파일로 게시하며 부분 파일을 평가 입력으로 쓰지 않는다. 임의 URL이나 실행 파일을 실행하지 않는다.

- 최초 원시 ZIP은26,214,400바이트 후 timeout, 경보 ZIP은30,089,740바이트 후 조기 EOF로 실패했다.
  실패 기록은 `runtime/f1/public-source-catalog-20261112/acquisition-batch.json`에 보존한다.
- 경보 ZIP 이어받기 성공:96,202,946바이트, MD5검증 통과, SHA256
  `9f0595c4ebe56ac9223763881f55369dd4f249a8108064e4ae108eb3309aeeb9`.
- 시간 구간 labels.csv는3,703바이트 수집·해시 검증만 완료했고 본문은 아직 읽지 않았다.
- 원시 ZIP은 아직 수집 중이다. 최종 파일 검증 전 원시 행별 정답 대조/새 성능을 보고하지 않는다.

`bounded_zip.py`는 디렉터리 인덱스·파일 수·크기·경로·중복·종류를 먼저 검사한다.
전체 압축을 풀지 않고 선택한 개발 멤버만 불투명한 로컬 파일명으로 CRC/해시 검증하며 읽는다.
실행·심볼릭 링크 추적·임의 경로 추출은 하지 않는다.512MiB 초과 멤버는 현재 한도상 읽지 않고
제외 사실을 기록한다. 나중에 이를 평가 분모에서 성능에 따라 삭제하지 않는다.

경보 ZIP의 인덱스16개를 확인했고 개발용 russellmitchell의 두 멤버만 읽었다.
JSONL과 실제 입력 스키마를 확인했으며 원시 행, 센서 결과, 라벨은 별도 단계에서 다룬다.
Wazuh의 `@timestamp`와 AMiner의 이벤트/탐지 시각을 실제 인증 신호의 신선도로 가장하지 않는다.

최종 예약 본문과 라벨은 후보 동결 전에 읽지 않는다. 정답·라벨 규칙·공격자 실행 기록·분할/시나리오
이름·절대 시각·사용자/호스트/IP 암기는 분류 특징으로 쓰지 않는다. 식별자는 연결·중복 점검에만 쓴다.
센서 설명이나 원문은 관측 데이터이며 시스템 지시가 아니다.

기기 정상·관리됨·계정 활성·MFA·역할·업무 승인이 원문에 없으면 unknown을 유지한다.
실패한 파싱·추론·판단 보류를 이미 정답이 있는 모집단에서 빼고 점수를 올리지 않는다.
실제 원시 전체 탐지 평가, 경보 후처리 평가, 기능/보안 회귀를 각각 보고한다.
전체 여섯 탐지 영역을 대표하지 못하는 새 자료는 그 한계를 명시하고 전체 목표 달성으로 처리하지 않는다.

## 실제 개발 입력 변환 결과

`python -m scripts.prepare_native_alerts`는 고정 SHA의 JSONL을 같은 파일 핸들에서 전후 검증한다.
큰 행·중복 JSON 키·비유한 수·잘못된 UTF8·스키마 오류를 조용히 버리지 않고 행별 오류로 남긴다.
`inputs.jsonl`에는 정답·주체 식별자·출처 경로·시각을 넣지 않는다. 센서/심각도/고정 의미 어휘만
분류 후보 특징으로 추출한다. `references.jsonl`에는 원본 행/해시·주체·시각·원시 행 해시를 따로 보관한다.
원시 로그 행의 공백을 지워 다른 행을 같은 정답으로 합치지 않는다.

russellmitchell 개발 시나리오의 실제 **45,544행**(Wazuh41,488·AMiner4,056)을 변환했다.
파싱 오류0·관측 스키마 오류0이며 원본 전체 행을 유지했다. 명시되지 않은 여섯 신뢰 주장은 모두 null이다.
이는 모델/탐지 점수나 정상·위협 라벨 개수가 아니다. **분류기 학습과 새 성능 평가는 아직 수행하지 않았다.**
변환 원자료는 `runtime/f1/ait-ads-native-inputs-{wazuh,aminer}-20261112/preparation.json`이다.
관측 특징/식별자 분리와 행 해시는 이후 정확한 행별 정답 대응 및 오탐 후보 비교에 사용한다.
