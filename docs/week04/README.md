# 4주차 산출물 및 가속 개발 기준

## 목표

3주차에 보류한 정책 필드와 자동 평가 구조를 확정하고, 이후 주차에 예정된 반복 평가·통합 API·배포 기반을 실험 브랜치에서 앞당겨 연결한다. 실제 계정이나 권한을 변경하지 않는 시뮬레이션 원칙은 유지한다.

## 완료 항목

- 시나리오 관찰 신호를 허용된 연산자와 필드 경로로 구성한 `detection_conditions`로 구조화
- 모든 합성 이벤트가 자신의 시나리오 조건과 일치하는지 자동 검증
- 정책 예외에 식별자, 승인자, 사유, 유효기간, 사용자·역할·자원·행위·최대 전송량 범위 추가
- 만료되거나 적용 범위를 벗어난 예외를 입력 단계에서 거부
- 비다운로드 행위의 전송량, 원격 접근 방식, MFA 실패 횟수 등 교차 필드 검증
- 위험 점수보다 낮은 위험 단계가 반환될 때 보수적으로 상향하고 사람 검토로 전환
- 10개 Few-shot 예시 쌍과 프롬프트 인젝션형 데이터 예시 추가
- 단건·제한 병렬 분석, 시나리오 매칭, 반복 평가 API 통합
- 규칙 기반 기준 사례의 위험도·대응 정확도와 JSON 유효율 자동 측정
- AWS Lambda 컨테이너와 DynamoDB 감사 저장소 배포 정의

## 계획 대비 앞당긴 항목

| 계획 구간 | 앞당긴 결과 |
|---|---|
| 5~6주차 | 10개 Few-shot 예시, 구조화 출력 입력 구성, 1차 자동 평가 |
| 7~8주차 | 최대 20건 제한 병렬 분석과 전체 파이프라인 통합 |
| 9~10주차 | 위험 점수 일관성, 파괴적 대응 검토, 예외 범위 검증 |
| 11~12주차 | 정확도·F1·JSON 유효율·평균/P95 응답시간 API와 화면 |
| 배포 준비 | ECR·Lambda·DynamoDB 및 대상 계정 검증 스크립트 |

## 검증 기준

- 위험도 정확도 70% 이상
- JSON 유효율 90% 이상
- P95 응답시간 3초 이내
- 합성 시나리오 8건 모두 구조화 조건으로 자기 시나리오와 일치
- 실제 대응 실행 경로 없음

OpenAI 모드의 실제 반복 호출과 AWS 실배포는 각각 유효한 API 키와 대상 계정 `172585182454` 자격 증명이 있을 때만 수행한다.
