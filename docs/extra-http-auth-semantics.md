## 구현한 관측

새 `raw-http-auth-semantics-4` 프로필을 추가했다. 기존 base/HTTP/VPN 프로필과 준비 명령 기본값은 유지한다.
HTTP는 최대2회 percent decode,64개 이하 쿼리 파라미터, 경로 깊이/확장자 종류·SQL/쉘/템플릿 문법 모양,
중복 쿼리 키·인코딩 오류·주장된 user-agent의 큰 종류를 관측한다. 원래 경로/키/계정/호스트 문자열은 학습 값으로 내보내지 않는다.
문자열이 공격 모양이라는 관측과 실제 악성·권한 위반 정답은 다르다. 입력의 명령/템플릿은 실행하지 않는다.

인증 로그는 프로세스와 명시된 로컬 계정을 구분하고, 같은 물리 소스에서 해당 계정의 이전60초 활동을 본다.
현재 행을 넣기 전에 질의하며 동일 시각은 **같은 파일의 앞선 ordinal**만 사용한다. 다른 소스의 같은 초를 과거로 추정하지 않는다.
실패/민감 파일/권한 도구 관측을 집계하며 공격 정답을 보고 과거 기록을 제외하지 않는다.
일치한 계정 문자열도 동일 사람·현재 신뢰·정상 업무 승인으로 인증하지 않는다.

감사 UID는 관측된 범주만 표현한다. 결측·범위 밖·unset sentinel·할당된 로그인 UID/세션을 구분한다.
HTTP 텍스트에 적힌 `uid=0` 등을 감사 로그의 권한 있는 사실로 바꾸지 않는다.
누락된 기기 건강·MFA·자원 소유 정책·조직 승인은 채우지 않는다. 정답/참조 sidecar는 그대로 복사하고 실패 행도 남긴다.

관련 최종 Windows287개·격리 Linux287개가 통과했다. 실패/오류/건너뜀0이며 Linux458파일 전후 및 현재 지문을 대조했다.

기존 RBA 감사의 실제 디스크 여유 검사에서 실패했다. 검사 기준을 낮추거나 모의로 통과시키지 않았다.
첫 데이터 준비도 ENOSPC로 중단됐다. 완료된 R은 지문 대조 후 재사용하고 실패한 S 산출물은 그대로 남긴 뒤 새 디렉터리에 다시 준비했다.

완료된 생성 파일은 [Windows compact의 파일 압축](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/compact)을
정확한 파일에만 적용하고 전후 논리 바이트/SHA를 대조했다. 운영체제 압축·Docker 데몬·다른 서비스는 바꾸지 않았다.
큰 산출물 지문은 스트리밍으로 계산한다. C 드라이브 용량은 다른 프로세스의 영향도 받으므로 항상 여유를 다시 확인한다.

실패 receipt/범위 로그는 남고, 원래 prefix는 완성 ZIP의 처음 같은 바이트 수로 정확히 복원 가능하다.
