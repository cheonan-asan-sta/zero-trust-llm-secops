# 기술 비교와 선정 대장

## 11월 13일 현재 판정과 11월 16일 마감

아래 날짜별 기록은 당시 수행 이력이다. 현재 개발 마감은 **11월 16일 월요일**이며
11월 22일 이후 일정을 현재의 미뤄진 마감으로 해석하지 않는다.
[앱 인수 대조](../kim-handoff-ready-20261113.md)는 PR #55 병합 후 CI의 16개 작업과
런타임 419개 검사를 연결한다. 인프라 구성 및 실측은 채희주 담당이고 자동 대조는
사람의 독립 재현 또는 운영 승인으로 대신하지 않는다.

위 보류는 김택희의 마감 제안이다. 두 사람이 채택을 승인한 기록은 아니며 미측정 후보가
성능 비교에서 뒤졌다고 표현하지 않는다. 과거 표의 C10 실행기/실험 미완료 상태는
현재 구현을 나타내지 않는다. [평가 결과와 한계](../kim-midnight-closeout-20261113.md)를 우선한다.

개발 로드맵 후속 [CA·DB·NGINX·Lambda·테스트 이미지 확장 검사](../seven-image-supply-chain.md): 동일 소스·갱신 DB의 일곱 이미지 검증과 Git 원본 LF 자료를 읽기 전용으로 제공한 Linux2728 통과. 첫 M7 CRLF 회귀4실패와 후속 LF 체크아웃 정책을 구분해 기록한다. 실제 실행 커밋에 범위를 고정하고 테스트 이미지의 후속 문서 입력 차이·미검사 builder/helper·독립 영향 검토/운영 승인 대기를 구분한다. 아래 과거 기록의 나머지 이미지 검사 대기는 이 후속 결과로 대체하며, 독립 영향 검토·운영 승인은 남는다. 아래 날짜·주차는 개발 로드맵 분류이며 실제 수행 주차나 기간 전체 완료가 아니다.

개발 로드맵 후속 [현재 앱·관측 이미지 공급망 재검사](../current-image-supply-chain.md): 앱 Grype191/Trivy194, 관측 Grype196/Trivy197 native 항목. 동일한 갱신 DB·3반복·원본 보존·소유 자원0, Linux2637. 앱 영향 독립 검토·나머지 이미지·C03 운영 선정은 남긴다. 아래 날짜·주차는 원계획의 분류이며 실제 수행 주차나 해당 기간 전체 완료를 뜻하지 않는다.

11/8 후속 [개인키 회차·자원 측정 구간 격리](../rekey-and-resource-measurement-isolation.md): PR47 첫 병합 후 개인키12개 중단과 자원 수집2건 실패를 보존한다. 시험은 동일 pending키/정확히1세대 증가를 검사하고, 관측v2는 준비·실제 부하·의도적 장애 구간을 구분한다. 로컬22/37·Linux2577·소유 자원0이며 새 정확한 head/병합 후 CI는 후속 PR을 따른다. C01/C02 로컬 조건부·C03 보류·독립 인수/3주차 전체 미완료는 유지한다.

11/8 3주차 잔여 묶음: [인프라 조건부 선정·현재 mTLS 부하/복구](../infrastructure-selection-acceptance.md). 채희주가 동시성1/4/8·3반복의576요청(153허용/423거부), gateway장애3회 전달0·새 grant복구, 인증된 관측·37개 인수와 Linux2560개를 검증했다. 과거 후보 비교 지문과 현재 실행 증거를 연결해 C01/C02는 로컬 조건부, C03는 현재 이미지 재검사/앱 영향 독립 대조 전 보류한다. 운영 승인·대안 후보의 현재 부하 새 비교·팀원 독립 재현·3주차 전체 완료와 구분하며 정확한 head/병합 후 CI는 PR을 따른다.
