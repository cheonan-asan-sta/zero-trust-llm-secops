# 기술 비교와 선정 대장

2026년 11월 1일 작성, 11월 3일 진행 갱신. 이 대장은 [비교 실행 계획](../technology-selection-plan.md)의 상태를 관리한다. C03 첫 로컬 비교와 M6/C10 계약을 진행했다. 채택·독립 재현은 완료되지 않았으며 아래 기한은 목표다. 실제 수행 범위는 각 기록을 확인한다.

인프라 후보의 구성·실행·장애 주입·자원/지연 측정·집계·원자료·선정 근거는 채희주가 주담당한다. 김택희는 인가 API·앱 지표·기능/상태 시험과 결과 대조·독립 재현을 맡는다. M6/C10 모델 평가 실행기·집계는 기존 김택희 역할을 유지한다. 결정 기록에 실제 실행자·측정자·검증자를 구분한다.

후속 결과 파일은 `C01-observability.md`처럼 ID와 영역명으로 추가하고 원자료·설정·재현 결과에 연결한다. 작성에는 [선정 근거 양식](decision-template.md)을 사용한다. 실행하지 않은 후보는 문서 조사·미측정으로 남긴다. `실제 비교 미완료`와 `도입 보류 결정 완료`를 구분한다.

자체 대시보드는 사용자 결정에 따라 기존 화면을 확장한다. 이 결정은 외부 대시보드와 성능 비교에서 승리했다는 결과로 기록하지 않는다.
