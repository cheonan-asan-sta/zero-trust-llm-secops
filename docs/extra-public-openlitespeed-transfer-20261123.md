# OpenLiteSpeed 공개 로그 전이 평가

2026-11-23 · `extra` · 발행자 공개 자료의 Organization Y · CPU 로컬 평가.

## 범위

발행자가 기술한 4월 29일 사건일과 양옆 날짜를 포함해 2025년 4월 28~30일로 표시된 웹 접근 회전 로그 32개를 예측 전에 고정했다. 전체 배포본의 MD5 `b1925ff7f043c391d501cfd404e0df10`과 SHA-256 `4e0aa82b126ef687a967b1086f449dd4b0aaf78774197bbc4b2082a944878dcf`를 확인했다. 물리 행 1,486,913개에 기존 웹 모델과 동결된 성공 POST 보정을 적용하고, 분리된 채점 단계에서 봉인된 예측을 발행자 YAML과 대조했다. 동일 ID의 대체 규칙도 유지했다. 선택 기간은 사건 범위의 재현을 위한 것이며 전체 사이트·전체 기간의 대표 표본으로 해석하지 않는다. [발행자 자료와 라벨](https://zenodo.org/records/20001206)

## 결과

| 동일 물리 행 | 정밀도 | 재현율 | F1 | 오탐률 | TP / FP / FN / TN |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 웹 모델 | 0.0119% | 51.05% | 0.0238% | 82.47% | 146 / 1,225,949 / 140 / 260,678 |
| 기존 성공 POST 보정 추가 | 0.0193% | 51.05% | 0.0385% | 50.93% | 146 / 757,073 / 140 / 729,554 |

오탐은 468,876행 감소했으며 추론 오류·새 오탐·기존 탐지 손실은 각각 0행이었다. 발행자 규칙이 분류한 위협은 286행이며 전부 리다이렉트와 그 외 요청에 속했다. 성공 POST 1,078,911행에는 발행자 양성이 없어 성공 POST에 대한 위협 보존 성능은 계산할 수 없다. 발행자 규칙과 일치하지 않는 행을 음성으로 채점한 수치여서, 사람이 각 요청을 독립적으로 확인한 결과와는 범위가 다르다.

성공 POST 위협 라벨이 있던 [SR-BH 평가](extra-public-successful-post-transfer-20261123.md)에서는 같은 보정이 기존 탐지를 10,296건 잃었다. OpenLiteSpeed에서 오탐이 줄었다는 이유로 보정을 활성화하지 않았다. OpenLiteSpeed 접근 로그에는 요청 본문과 승인·현재 세션, 서버의 Location 값을 함께 확인할 필드가 없다. 그 값을 만들어 넣지 않았고 본문 기반 CRS 성능도 이 자료에 대해 미측정으로 남겼다.

## 재현과 후속

`python -m scripts.evaluate_public_openlitespeed <archive> <new-output>`으로 예측과 봉인을 저장한다. 같은 명령에 `--score-seal <seal.json의 SHA-256>`을 붙이면 채점한다. Windows 로컬에서 예측과 봉인에 315.01초가 걸렸다. [실행기](../scripts/evaluate_public_openlitespeed.py) · [집계와 봉인 지문](infrastructure-results/public-openlitespeed-transfer-20261123.json)

다음 후보는 서버에서 확인한 요청별 인증·권한과 앱 처리 결과의 연결을 우선한다. `extra`의 [로컬 수집기](extra-web-verified-context.md#2026-11-23-로컬-응답-관측)에 응답 Location 해시 관측을 추가했다. 관측 값 자체는 접근 권한을 변경하지 않는다. 최종 채택은 정상·위협을 함께 담은 별도 자료에서 기존 탐지 손실과 새 오탐을 점검하고 정밀도·재현율·F1 각각 95% 이상, 오탐률 5% 이하를 확인한 뒤 판단한다.
