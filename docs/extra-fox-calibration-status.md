후속 [v39 정상 웹 오탐 감소](extra-web-false-positive-reduction.md)는 같은 전체 입력에서 별도 HTTP 보정 후보를 비교한 결과다.
이 문서의 v36 수집 실패와 v37~v38 고정 모델 결과는 보존하며 새 후보/운영 채택과 구분한다.

최신 v37~v38은 [스트리밍 복구·전체 보정·점수 진단](extra-streaming-fox-calibration.md)에서 확인한다.
668,418행 전체 준비/고정 모델 비교를 완료했고 기존 기본 입력·정답·참조 해시를 재현했다.
기본 관측별 후보의 Fox F1은99.7194%지만 웹 정상 오탐23.21% 등 약점과 원래 여섯 영역의 독립 최종 평가가 남는다.
아래 실패 기록은 덮어쓰지 않았다. 모델/임계값 채택이나 전체 목표 달성으로 해석하지 않는다.

## v36 중단 당시 기록

2026-11-12 · v36 당시에는 **수집과 원시 대응은 완료, 보정 추론/지표는 미실행**이었다.
[실행 근거](infrastructure-results/extra-fox-calibration-v36-20261112.json)를 따른다.
원래 보정용으로 선언한 fox이며 최종 예약 harrison/wilson과 구분한다.

ZIP688,586,900바이트를2264.297초에 수집했다. 발행자 MD5를 대조했고 저장된 파일의 SHA256도
`8d71d31a31df469d836c80bdbfdc35da566e90322cf9ae490233e176a0c88d49`로 별도 확인했다.
체크섬은 발행자의 전자서명이라는 뜻이 아니다. 멤버 본문을 읽기 전에 v34 두 모델을 동결했다.

물리적으로 대응하는 원시/라벨8쌍을 CRC·SHA·행 번호·호스트 UTC와 대조했다.
총668,418행: 출처의 정상211,534·공격456,884행이다. 모든 원시 행을 기본 관측으로 준비했으나
새 의미/시간창 입력을 생성하다 디스크 부족으로 중단됐다. 두 모델의 예측 실행에는 도달하지 않았다.
부분 점수·작은 부분집합의 F1·0% 성능으로 대체하지 않으며 **보정 지표는 없음**으로 남긴다.

독립적으로 같은 원시 파일을 검사해 웹 접근412,922행 중 HTTP 요청412,904개를 확인했다.
기존 준비기의 소스별10만 요청 메모리 상한도 초과한다. 이번 실패는 ENOSPC였으며,
요청 상한 초과는 별도 확인한 추가 제약이다. 상한이 실제 예외 원인이었다고 바꾸어 기록하지 않는다.
자료를10만 개로 잘라 점수를 내거나 보호 한도를 조용히 늘리지 않았다.

디스크 복구 시 원시/정답/실패 부분 파일은 유지했다. 완료됐던 기본 입력 캐시509,996,520바이트만
지문 대조 후 정리했다. 원본 쌍·코드·기대 SHA로 재생성할 수 있고 복원 방법은
`runtime/f1/fox-calibration-v34-20261112/storage-recovery.json`에 있다.
과거 기본 준비 receipt의 완료는 당시의 결과이며, 현재 캐시가 모두 남아 있다는 뜻은 아니다.
현재는 캐시 재생성 또는 새 스트리밍 경로가 필요하다. 실패 부분 파일은 무손실 압축 전후 SHA가 같다.

다음 작업은 다음 조건을 갖춘 스트리밍 준비기다.

1. 기본/확장 입력과 정답/참조를 여러 번 복제하지 않고 필요한 중간 저장량을 먼저 예산화한다.
2. HTTP는 제한된 디스크 정렬로 시각+원래 ordinal 순서를 보존하고, 시간창 카운터는 매번 전체 큐를 훑지 않도록 한다.
3. 기존 R/S의 특징·고정 모델 예측을 정확히 재현해 관측 계약이 달라지지 않았음을 확인한다.
4. 전체668,418행과 오류/미지원 사례를 유지하고, 재학습 없이 같은 두 모델을 먼저 비교한다.
5. 새 구현의 자원 한도·시간/동시각/중복·중단/복구를 시험한 뒤 보정 결과를 산출한다.
