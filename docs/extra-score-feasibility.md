# 고정 점수의 목표 도달 가능성 진단

## 목적과 해석

오탐·미탐 개선에서 먼저 확인할 것은 현재 점수의 임계값만 바꿔 목표를 만족할 수 있는지다. 이 도구는 이미 예측·채점한 v85 전체1,681,815행을 보존하고, **점수가 같은 모든 행을 함께 이동**시키며 가능한 점수 경계 전부를 계산한다. 정답을 사용하는 사후 진단이며 모델 학습·새 예측·임계값 채택·새 독립 평가는 하지 않는다.

도구는 `scripts/f1_lab/score_feasibility.py`와 `python -m scripts.run_score_feasibility`다. 실제 앱의 분석기나 정책 집행 경로에 연결하지 않는다. 한 점수 투영에서 불가능하다는 결과가 더 풍부한 원문 문맥·새 인증 신호·다른 모델에서도 불가능하다는 뜻은 아니다. 반대로 관측 정답에서 가능한 경계가 나와도 새 자료에서 재현되기 전에는 채택 근거가 아니다.

## 목표와 계산 경계

P는 위협 행 수, N은 정상 행 수다. 각 경계의 TP·FP에서 FN=P−TP, TN=N−FP로 계산한다. 다음을 **정수 교차곱**으로 모두 확인해95% 경계의 부동소수점 반올림을 피한다.

- 정밀도≥95%: `20·TP ≥ 19·(TP+FP)`.
- 재현율≥95% / 미탐률≤5%: `20·TP ≥ 19·P`.
- F1≥95%: `40·TP ≥ 19·(TP+FP+P)`.
- 오탐률≤5%: `20·FP ≤ N`.

P 또는 N이0이면 전체 목표 통과로 표시하지 않는다. 알려진 정답의 추론 실패는 기존 채점과 같이 위협이면 FN·정상이면 FP로 모든 경계에 남긴다. 실패 행·지원하지 않는 종류를 정상으로 바꾸거나 삭제하지 않는다. 같은 점수 안에서 정답을 보고 정상/위협을 따로 선택하지 않는다.

진단 결과는 현재 행렬, 경계 개수, 점수만으로 가능한 최고 F1, **새 FP0·기존 TP 손실0을 지키는** 경계 내 최고 F1, 각 조건을 모두 만족하는 경계 수를 구분한다. ‘최고’는 이미 노출된 정답에 대한 진단 상한이며 권고 임계값·새 모델 성능이 아니다. 원래 임계값0.95와 모델·라벨·판정 파일은 유지한다. 관측 점수보다 높은 모든 행 미경보 경계도 비교하지만 이것을 배포 가능한 구성으로 제안하지 않는다.

## 출처·전 행 보존·노출 기록

고정 plan의 외부 SHA, v85 실행 지문, 각 preparation/prediction/truth SHA를 확인한다. 원본 source SHA와 물리 행 순번으로 만든 case ID, prediction의 source index, 정답의 같은 case ID와 행 수를 모두 대조한다. 출처별/종류별 기존 TP·FP·FN·TN·오류·모집단을 재현하지 못하면 완료하지 않는다. 종료 때 코드와 입력 지문을 다시 확인한다. 출력은 새 디렉터리만 허용하며 실패 영수증은 incomplete로 남긴다.

R은 이미 관측한 학습·개발, S는 관측 개발, Fox는 사전 보정 역할을 유지한다. 이미 평가한 Harrison도 지금의 사후 진단에서는 관측 자료이며 새 holdout으로 표시하지 않는다. R/S/F 종류별 표와 Harrison 표를 구분하고 원래 전체 행을 모두 유지한다. 이 로그 종류는 원래 여섯 보안 영역의 독립 평가를 대신하지 않는다.

정답 파일은 해시 확인만으로도 본문을 읽는다. 따라서 무결성 확인 전과 실제 정답 해석 전의 접근 목적·역할·시각·정답 SHA를 append/fsync 대장에 남긴다. `labels_reopened_for_diagnostic=true`를 공개하며 예측기에는 새 정답을 전달하지 않는다. 원문·정답 행·실제 계정/호스트를 공개 결과에 복사하지 않고 집계와 지문만 기록한다.
