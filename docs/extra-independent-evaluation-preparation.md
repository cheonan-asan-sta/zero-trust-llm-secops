## 입력·분할·동결 계약

[준비 프로토콜](../infra/f1-lab/independent-evaluation-preparation.json)은 기존6개 입력의 SHA-256,
원래 목표, 평가 단위, 다섯 분리 축과 정상300·위협300 **최종 세션 확보 목표안**을 고정한다.
300+300은 표본 확보 계획이며 통계적 충분성·여섯 영역의 지지·독립성을 보장하지 않는다.

[메타데이터 검사 코드](../scripts/f1_lab/evaluation_preparation.py)는 아래 조건을 처리한다.

- 같은 세션·주체·기기·계열·패턴 또는 동일 payload가 연결되면 하나의 성분으로 묶는다.
  A↔B가 주체로, B↔C가 기기로 이어져도 A/B/C를 함께 검사한다.
  분할을 가로지르면 충돌을 보고하며 사례를 삭제하거나 자동 재배정하지 않는다.
- 미상 그룹은 공통 사용자/기기로 취급하지 않는다. 최종 후보의 필수 그룹이 비어 있거나
  namespace가 검증되지 않았으면 준비를 차단한다. 그룹 해시는 실제 신원 증명이 아니다.
- development→calibration→final_reserved가 모두 있어야 하며 각 앞 분할의 마지막 시각이
  다음 분할의 첫 시각보다 엄격히 빨라야 한다. 시간 경계만 통과해도 독립성 완료로 판단하지 않는다.
- 이미 본 출처/원본/관측/패턴과 겹친 최종 후보를 차단한다. 출처 ID만 바꾸어도
  동일 원본·관측 지문이 남아 있으면 노출 검사에 걸린다. 의미가 같은 모든 변형의 자동 식별은 아니다.
- `sealed_unseen` 사례에는 라벨을 전달할 수 없다. `unknown`도 정상으로 바꾸지 않는다.
  기기 상태·MFA·권한·업무 승인 같은 실제 보안 필드를 정상 기본값으로 만들어 넣지 않는다.
- 이벤트 탐지, 세션 경보, 정책 기능 제어군은 단위를 나누어 집계한다.
  정책상 경보가 기대된다는 라벨을 실제 악성 정답으로 사용하지 않는다.

준비 프로토콜은 `stage=preparation_only`, `candidate_freeze_sha256=null`만 허용한다.
유효한 메타데이터 예시가 있어도 최종 평가 준비/독립 검토 완료/목표 달성을 출력하지 않는다.
이는 **후보 동결 이후 최종 평가를 실행하는 도구가 아니다.** 현재 CLI는 고정된 기존 자료의 준비
패킷을 만드는 경로이며 새 공개 원본의 메타데이터 어댑터·라벨 심사·최종 실행기는 후속 작업이다.

출력8파일(프로토콜, 사례 목록, 노출 대장, 연결 성분, 준비 보고서, 출처 목록, 오류 검토 목록,
동결 manifest)의 정확한 목록과 지문을 검증한다. 기존 출력은 덮어쓰지 않는다.
지문은 준비 산출물의 무결성 확인이며 후보 모델 동결이나 독립 검토자 확인을 대신하지 않는다.

## 오류 검토 목록과 다음 순서

합성 기준선의 기존 증거220건을 사례 ID까지 보존해22계열로 묶었다.
FP/FN200건 외에 다른 규칙이 탐지했지만 기대 규칙은 놓친 TP20건도 포함한다.
규칙 추적·누락 요구 역할·미상 기기/MFA·서명되지 않은 예외 주장 여부는 관측 사실로만 기록한다.
검토자 식별자는 비워 두며 원인/라벨 변경/독립 검토를 자동 승인하지 않는다.

공개 로그22개 항목은 기존 자료별·파일별 alert 집계에서 FP 또는 FN이 있는 대상이다.
원시 행을 다시 읽지 않았으므로 사례별 ID 목록은 아직 없고 `case_inventory_available=false`다.
따라서 44개를 모두 서로 독립적인 공격 사례나 원인 검토 완료 건수로 표현하지 않는다.

|---|---|---|
| 1 | 기존 합성22계열과 웹 access/error 잔여 FP/FN의 개별 관측 검토 | POST·redirect·body/권한 문맥·Fox error 미탐 등을 대조. 넓은 정상 예외를 만들지 않음 |

`259bbb3c4192899c3513a2af4b848208be9c4deb0edb2dbe3f0f0a1a136b7d78`

실제 로컬 준비 패킷은 `runtime/f1/independent-preparation-v43-20261113`이며 동결 지문은
`d57753a97ee72b25799338102432c4657e0d73f46a61e2a46849601d369bd54c`다.

```powershell
.venv\Scripts\python.exe -m scripts.prepare_independent_evaluation prepare --protocol infra/f1-lab/independent-evaluation-preparation.json --expected-sha256 259bbb3c4192899c3513a2af4b848208be9c4deb0edb2dbe3f0f0a1a136b7d78 --directory runtime/f1/independent-preparation-new

```
