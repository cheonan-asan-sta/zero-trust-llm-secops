# 저장된 HTTP 요청 대상의 CRS 탐지 보강

2026년 11월 25일 · `extra` 후보 `3ae54ba` · 로컬 CPU 평가.

[후속 우선 검토 분리](extra-public-web-crs-priority-20261125.md)에서 Apache의 정상 라벨 76건 중 9건만 우선 검토로 남겼다. 나머지 CRS 신호는 일반 검토에 보존했다.

## 기존 미탐과 변경

공개 합성 HTTP 요청 791건에서 기존 웹 모델은 발행자 정상·위협 라벨에 관계없이 0.066405로 동일한 점수를 냈다. 경보 임계값 0.95를 낮춰도 이 점수만으로 두 집단을 구분할 수 없다.

기존 로컬 Coraza 3.8.1·OWASP CRS 4.25.0 실행기에 저장된 메서드와 요청 대상만 확인하는 옵션을 추가했다. 두 요청 단계에서 SQL 삽입, 스크립트 삽입, 명령 실행, 파일 포함 계열 규칙의 관측을 사용했다. 프로토콜·헤더·본문이 없는 로그에서 해당 값들을 만들거나, 결측을 위협으로 점수화하지 않았다. 규칙의 관측만 수집하는 모드이며 HTTP 요청을 재전송하지 않는다. 회귀에서는 기존 경보에 새 신호를 더했고 기존 판단을 낮추는 처리는 적용하지 않았다.

## 기존 자료에서의 재평가

| 같은 자료에서 비교 | 정밀도 | 재현율 | F1 | 오탐률 | TP / FP / FN / TN |
| --- | ---: | ---: | ---: | ---: | ---: |
| 합성 HTTP 791건 · 기존 | 계산 불가 | 0.00% | 0.00% | 0.00% | 0 / 0 / 72 / 719 |
| 합성 HTTP 791건 · 기존 또는 CRS | 100.00% | 73.61% | 84.80% | 0.00% | 53 / 0 / 19 / 719 |
| 공개 Apache 213,205행 · 기존 | 1.26% | 80.92% | 2.49% | 16.23% | 441 / 34,506 / 104 / 178,154 |
| 공개 Apache 213,205행 · 기존 또는 CRS | 1.46% | 94.13% | 2.88% | 16.26% | 513 / 34,582 / 32 / 178,078 |

합성 자료에서 놓친 위협 72건 중 53건을 새로 잡았고, 정상 719건의 오탐은 유지됐다. 남은 19건의 발행자 라벨은 관리자 경로 탐색 12건, 명령 삽입 5건, 민감 파일 탐색 2건이다. 공개 Apache에서는 미탐 72건을 회복했으나 새 오탐 76건이 생겼다. 두 자료에서 기존 탐지 손실은 0건이었다.

Apache에서 일치 규칙을 2개 이상 요구할 때는 66건을 회복하고 새 오탐 60건이 생겼다. 3개 이상에서는 25건을 회복하고 새 오탐 21건이 생겼다. 일치 개수만 바꾼 두 기준에서도 새 오탐을 제거하지 못했다.

이전 평가에서 이미 본 두 공개 자료의 개발·회귀 결과다. 새 독립 표본 성능은 미측정이다. 두 자료에서 네 목표를 동시에 충족하지 못했고, Apache의 오탐이 증가해 운영 탐지 기준에 연결하는 작업은 보류했다. [합성 HTTP 평가](extra-public-web-access-independent-20261125.md) · [Apache 평가](extra-public-priority-evaluation-20261123.md)

## 재현

로컬 웹 회귀 159개와 Ruff가 통과했다. 기존 전체 요청 검사 모드에서 과거 SR-BH 제어 64건의 결과가 이전 바이너리와 바이트 단위로 동일했다. AWS와 유료 API 호출은 0회였다. [집계와 봉인](infrastructure-results/public-web-target-crs-20261125.json)

[이전 자료의 봉인](extra-public-web-access-independent-20261125.md#재현과-증적) 또는 [Apache의 봉인](extra-public-priority-evaluation-20261123.md#재현)을 확보한다. `scripts/experiments/crs_shadow`에서 `go build -trimpath`로 로컬 바이너리를 만든 뒤, 저장소 루트에서 아래 명령을 사용한다. `access|apache` 중 실제 자료에 맞는 하나를 선택한다.

```powershell
python -m scripts.evaluate_public_web_target_crs capture <access|apache> <원본> <이전-봉인-폴더> <새-출력> <이전-seal-SHA256> <CRS-바이너리>
Get-FileHash <새-출력>/seal.json -Algorithm SHA256
python -m scripts.evaluate_public_web_target_crs score <access|apache> <원본> <이전-봉인-폴더> <새-출력> <이전-seal-SHA256> <새-seal-SHA256>
```
