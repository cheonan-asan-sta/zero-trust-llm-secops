## 오탐 원인과 구현 변경

- **분류 의미 혼동:** 경보 조건 일치, 무단·악성 행위, 접속 허용을 분리했다. 정상 분류는 이 문맥에서 위협 근거가 없다는 뜻이며 실제 사람의 신원이나 접근 권한이 검증됐다는 뜻이 아니다. 일반적으로 확인되지 않은 외부 배경만으로 UNKNOWN을 만들지 않되, 판정에 필요한 관측이 빠졌다면 UNKNOWN과 검토를 유지한다.
- **조건 비교 오류:** 역할이 같은 관리자 작업을 권한 상승으로 분류한 응답이 있었다. 서버가 역할 주장 값의 동등 여부만 계산해 전달한다. 이는 탐지 정답이나 권한 판정이 아니다. 각 정책은 독립적으로 평가하도록 지시해, 성공한 인증이 별개의 역할 불일치를 상쇄하지 않게 했다.
- **예외 문맥 누락:** `PolicyException.applies_to`로 시각·사용자·역할·자원·행동·전송량 범위를 다시 비교한다. 발급자 권한은 검증하지 않았다고 항상 명시한다. 실제 보안 장비의 허용이나 신원 증명으로 사용하지 않는다. 해당 업무의 설명 가능한 예외와 별개의 MFA 실패·비활성 계정·침해 기기 관측을 구분한다.
- **원격 값 투영 누락:** 기존 정책에서 읽는 OCSF `is_remote`가 프롬프트용 투영에서 누락돼 있어 포함했다. 이 수정이 원격 미탐을 모두 해결했다는 뜻은 아니다.
- **응답 오류와 추론 오류 구분:** 없는 근거 경로·null 경로는 계속 거절한다. 유효한 근거의 중복만 순서를 유지해 제거한다. 원본 목록의 모든 경로를 먼저 검사하므로, 중복 사이의 없는 근거를 삭제해 통과시키지 않는다. 분류·위험·권고는 바꾸지 않는다. 과거 중복 거절 실험은 당시 점수 그대로 남겼다.

모델에 benchmark 정답·사례 ID·예상 rule ID를 보내거나 반환된 분류를 정답으로 바꾸지 않았다. 역할 비교와 예외 범위 확인은 입력 주장에 대한 계산일 뿐 신뢰할 수 있는 issuer 검증이 아니다. 모델의 의미적 근거 타당성은 필드 경로 enum만으로 검증되지 않는다.

## 비교와 실패 보존 방법

직전 24건은 TP10/FP6/FN2/TN6, 직전12건은 TP6/FP2/FN0/TN4였다. 새 비교에서는 이전 `inputs.jsonl`의 grounded 요청을 그대로 다시 호출해 현재 후보와 비교했다. 재생 때 원본 계획의 입력 SHA, 사례 SHA, 모델 버전을 검사하며 이전 truth나 응답을 프롬프트 생성에 읽지 않는다. 채점에만 기존 정답을 사용한다. v2에서 baseline을 재생한 당시의 non-null 근거 enum과 검증 동작은 원래 baseline과 같았다. 최신 CLI로 향후 재생하면 최신 검증기를 사용하므로 이는 원문 입력 재생이며 과거 검증기까지 복원하는 기능은 아니다.

실행 순서에 따른 편향을 줄이기 위해 baseline/candidate 순서를 사례별로 교차한다. 한 번의 좋은 결과로 채택하지 않고 24건을 반복한다. 거절·UNKNOWN·미시도는 정상에서 FP, 위협에서 FN으로 집계한다. 이 FPR은 실패 포함 보수 집계이며 실제 경보 오탐률과 구분한다.

[비교 실행기](../scripts/compare_llm_grounded.py)는 같은 사례 집합과 라벨을 요구하고, 기존 TP를 잃은 사례를 ID로 기록한다. FN 총수가 같더라도 다른 위협을 새로 탐지해 이전 TP 손실을 가린 경우는 실패다. 중복·누락 사례나 라벨 변경도 비교에서 거절한다.

초기 v2의 24건 첫 비교는 FP6→2·FN2 유지였지만, 반복 실행에서 역할 불일치 위협을 정상으로 분류해 FN3이 됐다. 따라서 v2는 채택하지 않는다. v3에서는 mini의 reasoning을 low로 바꾸고 역할 비교·독립 정책 평가를 보강했다. 서로 다른 변수를 함께 바꿨으므로 개별 수정의 인과 효과로 분리해 주장하지 않는다. 중복 인용으로 올바른 위협 분류가 거절된 결과도 당시 점수 그대로 보존한다.

원본 사례 SHA256은 `de6ecc654b55450a9b5636dd29f08742c056e9be43c6458aabecf000a407775f`로 동일하다. 각 단계 시작 전 프로토콜과 소스 snapshot을 동결했다. 역할·예외 비교, 정책 원본, 정규화 코드, 실행기, 선택 profile 지문은 공개 JSON에서 확인할 수 있다. 정확한 입력과 raw/validated 응답은 로컬 runtime에 보존했다. 원문 응답을 수정하지 않았고 공개 JSON에는 사례별 분류·오류·토큰·지연·근거 개수와 원문 파일 SHA를 저장했다.

선택 profile [llm-grounded.example.env](../infra/llm-grounded.example.env)은 최종 측정 조건에 맞춰 mini 고정 버전·reasoning low·최대2400 출력 토큰으로 갱신했다. 실제 비밀 설정 파일은 수정하지 않았다. 예외 범위 검사·역할 비교·원격 값 투영·잘못된 근거 거절·중복 정규화·baseline 지문·누락/라벨 변경/TP 교환 거절 등을 포함한 로컬85건을 통과했다. 기존 라이브러리 deprecation 경고3건이 남아 있다.
