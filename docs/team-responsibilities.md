# 개인별 역할과 협업 기준

작성일: 2026년 11월 1일 · 적용 기간: 11/2~12/13 잠정 · 구현 기준: `aitest` v0.17.0

기존 수행계획서의 역할을 유지하면서 [멘토링 우선 주간 계획](mentoring-priority-roadmap.md)의 M1~M8·I1~I8을 개인별 실행 문서로 나눈다. 아래 내용은 앞으로 할 일이며 과거 개인 기여나 구현 완료를 증명하는 기록이 아니다.

**인프라의 구성·실행·측정은 채희주가 주담당한다.** 서버·네트워크·프록시·인증서·키·관측 도구·공급망 검사·배포·백업/복원 환경의 실행, 장애 주입과 자원·지연·복구 시간 측정을 포함한다. 김택희는 백엔드 API·처리·정책 상태·허용 소비·회수·저장 일관성, 애플리케이션 지표와 기능 시험을 맡는다. 인프라 시험의 주 실행자를 교차 검증자와 구분하며, 통합 결과는 두 사람이 확인한다.

주차별 두 사람의 담당과 공동 완료 기준은 [한눈에 보는 통합 표](역할분담_주간계획_한눈에보기.md)에서 확인한다.

## 공동 일정과 기록

매주 시작 시 범위·입출력·기대 판단·필요한 상대 작업을 맞춘다. 주중에는 최소 입력 예시·출력 예시·오류 범주·버전·재현 방법을 먼저 공유한다. 주말에는 상대가 새 실행 환경에서 재현하고 결과·남은 결함을 기록한다. 담당자가 바뀌면 이 문서와 두 개인 계획을 함께 수정한다.

도구 비교는 [기술 비교 실행 계획](technology-selection-plan.md)·[선정 대장](technology-decisions/README.md)·[근거 양식](technology-decisions/decision-template.md)을 사용한다. 11/8 계약·C03 첫 적용, 11/15 C01/C02 두 대안 최소 연결·C03 초안, 11/22 필수 3영역 선정/통합과 조건부 필요 판정, 11/29 비교 근거·교차 재현을 완료한다. 미측정 후보를 성능 순위에 포함하지 않고 시험이 미완료인 필수 항목은 이월 상태를 남긴다.

주간 보고서는 채희주가 설계·AI·인프라 변경과 직접 실행·측정한 수치·조건·한계를, 김택희가 백엔드·데이터·기능 시험·모델 평가 결과를 먼저 작성한다. 인스타도 채희주가 메시지·구조도·인프라 측정 수치를, 김택희가 백엔드/평가 수치·화면·조건을 제공하고 두 사람이 확인한다. 최종 보고서와 발표도 담당 부분을 작성한 뒤 통합한다. 게시·멘토 발송은 별도 팀 업무다.

11/29 기능 동결, 12/6 제출 가능본, 12/7~13 잠정 제출 일정을 따른다. 11/1 미완료 항목은 다음 주 최우선으로 이월한다. 개인별 문서는 같은 범위의 구체화이며 마감 연장이나 기능 추가의 근거가 아니다.

개발·장애 시험은 로컬 Docker Compose에서 수행한다. 실제 모델 API 비교는 사용자 허용 범위에서 한도를 정해 별도 실행한다. AWS 자원 생성·배포, GitHub 업로드와 실계정 차단은 수행하지 않는다. 현재 문서 작성에서는 API 호출이나 기능 구현을 하지 않았다.

## 역할 근거

기존 공유용 수행계획서의 「역할 분담 및 협업 방법」은 채희주를 전체 아키텍처·AI 프롬프트·구조화 출력·제로트러스트 정책 매핑·클라우드 환경 담당, 김택희를 FastAPI·합성 데이터·자동 테스트·대응 엔진 담당으로 명시한다. 원본은 작업공간의 `결과물/WE-Meet_수행계획서_및_지원금계획서_천안아산역.docx`다. 3~4주차 심화학습노트와 1~7주차 팀원 공유 자료의 역할 구분도 일치한다. 날짜와 기술 범위는 최신 주간 계획을 따른다.
