# 역할분담과 주간 실행 계획

11/7 DB 통신 자동 교체 묶음: [독립 전송 root·서버/client 키·중단 재개](database-transport-rotation.md). 채희주가 별도 보관함·서명 계획·고정 객체 정지/게시·실제 DB TLS 검증을 연결한다. 초기 Linux2383/관측75와 마지막 변조 검사46 중단을 보존했다. 예외 분류·실행기 중복 차단·시험 대기를 보완한 최종 소스의 집중229/신규47·Ruff·실제48/48·정리0을 별도 확인했다. 최종 전체 회귀/정확한 head·병합 후 CI는 PR을 따른다. DB/물리 HA·전체 백업 통합·독립 인수는 후속이다.

11/6 착수·11/7 검증 묶음: [DB 전송 PKI 사전 점검·관측 준비·로컬 일괄 검증](infrastructure-preflight-batch.md). 채희주가 만료/신원/키 권한 선검사와 현재 rule 평가 경계·소스/엔진 고정 실행을 구성한다. 집중236/신규59·고정 Ruff·로컬 Docker2340·관측75/75·authority38/38·소유 자원0을 확인했다. 정확한 clean head/병합 후 CI는 PR 기록을 따른다. DB 전송 인증서 자동 교체·DB/물리 HA·팀원 독립 인수는 후속이다.

11/6 기능 묶음: [CA/JWK 교체·CA 프로세스 이중화·병렬 CI](persistent-authority-rotation.md). 채희주가 인프라18서비스·공유 mTLS DB와 서명된 교체/복구 검증을 연결한다. 로컬 집중190/신규91·고정 Ruff·Docker2281·통합35/35·소유 자원0이며 정확한 head/병합 후 CI는 PR을 따른다. DB·물리 호스트 HA와 팀원 독립 인수는 후속이다.

11/6 CA 최초 발급 후속: [준비 상태·발급시각·replay 대조](ca-bootstrap-readiness.md). PR37 병합 전 성공과 병합 후 초기 발급 실패를 구분하며, CA 준비 확인 뒤 grant를 만드는 순서와 현재 시각의 재사용 차단 검사를 보강한다. 최종 실행 결과는 후속 원자료/PR을 따른다.

**대시보드는 기존 화면을 확장해 자체 개발한다.** 채희주는 화면 구성·도구 설정, 김택희는 조회 API·역할/테넌트 검사·지표를 주담당하고 화면 확장·통합은 공동 수행한다. Grafana·Perses는 필수 도입에서 제외한다. 메트릭/경보는 Prometheus+Alertmanager와 VictoriaMetrics+vmalert+Alertmanager, 접근 집행은 NGINX/Envoy 중 하나, 공급망 검사는 Syft·Grype/Trivy의 비교 후 선정한다. step-ca는 11/3 명시된 자동화 요청에 따라 C04 로컬 적용을 진행하며 운영 채택/독립 재현은 별도다. osquery는 여전히 조건부 후보로 미도입이다. 상세 조건은 전체 주간 계획의 오픈소스 선정 항목을 따른다.

개발·장애 시험은 **로컬 Docker**에서 진행한다. 유료 모델 비교는 사용자 허용 범위에서 요청·토큰·금액·시간 상한을 정해 별도로 실행한다. AWS 자원 생성·배포와 실계정 변경은 수행하지 않는다. GitHub 반영은 이후 사용자 요청에 따라 [이름 브랜치·PR 절차](contribution-workflow.md)를 따른다. 필수 세션·입력·집행 시험이 미달하면 추가 모델·검색·이상탐지·새 플랫폼은 이월한다.

M은 멘토링 피드백, I는 인프라 보완 항목이다. 세부 기준은 [전체 주간 계획](mentoring-priority-roadmap.md), 역할 경계는 [공동 협업 기준](team-responsibilities.md), 개인별 실행은 [채희주 계획](roles/chaeheeju.md)·[김택희 계획](roles/kimtaekhee.md)을 따른다. 모델명은 비교 후보이며 채택 완료를 뜻하지 않는다.

C는 [기술 비교·선정 계획](technology-selection-plan.md)의 항목이다. C01~C03 관측·집행·공급망 검사는 실제 적용 비교를 필수로 하고 인증서·기기 수집·전달·저장·인증·정책은 필요 판정 후 시험 또는 보류 근거를 남긴다. [선정 대장](technology-decisions/README.md)·[작성 양식](technology-decisions/decision-template.md)을 사용하고 설치·연결 성공만으로 비교 완료를 표시하지 않는다. 대시보드 자체 개발 결정은 유지한다.
