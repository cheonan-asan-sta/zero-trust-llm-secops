개발·장애 시험은 **로컬 Docker Compose**에서 진행한다. 유료 모델 비교는 사용자 허용 범위에서 요청·토큰·금액·시간 상한을 정해 별도로 실행한다. AWS 자원 생성·배포, GitHub 업로드와 실계정 변경은 수행하지 않는다. 필수 세션·입력·집행 시험이 미달하면 추가 모델·검색·이상탐지·새 플랫폼은 이월한다.

M은 멘토링 피드백, I는 인프라 보완 항목이다. 세부 기준은 [전체 주간 계획](mentoring-priority-roadmap.md), 역할 경계는 [공동 협업 기준](team-responsibilities.md), 개인별 실행은 [채희주 계획](roles/chaeheeju.md)·[김택희 계획](roles/kimtaekhee.md)을 따른다. 모델명은 비교 후보이며 채택 완료를 뜻하지 않는다.
