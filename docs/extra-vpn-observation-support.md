# VPN 연결 관측 구간별 평가 지지 — v59

2026-11-14 · 행 단위 탐지28건을 독립 공격28회로 해석하지 않도록,
예측이 이미 봉인되고 채점된 뒤 연결 관측 구간의 지지를 추가 집계한다.
**실제 인증 세션 수를 측정하거나 기존 F1의 분모를 바꾸는 기능은 아니다.**

## 고정된 집계 규칙

- 정확히 파싱되는 같은 물리 파일·IPv4/포트 끝점을 연결 키로 사용한다. 사용자 이름이 바뀌어도
  같은 네트워크 끝점이라는 관측만 남긴다. IP·이름을 인증된 사용자/기기라고 주장하지 않는다.
- 현재 순서에서 같은 끝점의 행 간격이60초 이하이면 같은 구간이다. 60초 초과·파일 경계·시각 역행은 나눈다.
  시각을 알 수 없는 행에서는 열린 구간을 닫고, 미상 시각/끝점 행은 미배정으로 별도 센다.
- 같은 시각 행을 묶는 것은 예측 후 지지 감사에만 사용한다. 이를 이전 탐지기의 과거 특징으로 되돌리지 않는다.
- 정상/위협 라벨이 함께 있는 구간은 혼합으로 공개한다. **정상 행에서만 경보가 울린 혼합 구간을
  위협 탐지 성공으로 세지 않는다.** 위협 라벨 행에서 경보가 있어야 탐지 구간으로 집계한다.
- 추론 오류·미상 관측·중복 물리 행을 제거하지 않는다. 원래 전 행 혼동행렬을 재계산하고 기존 결과와 같아야 한다.
- 구간 임계값은60초로 고정하며 결과에 맞춰 선택하지 않는다. 끝점 재사용/NAT 때문에 서로 다른 세션이
  합쳐지거나 한 세션이 여러 구간으로 나뉠 수 있어 독립 시행 수·세션 F1·신뢰구간을 주장하지 않는다.

## 구현과 실행 경계

[집계기](../scripts/f1_lab/vpn_observation_segments.py)는 정답을 쓰는 **사후 평가 전용 도구**다.
모델·임계값·접근 권한·기존 경보를 변경하지 않으며 실제 식별자 값을 결과에 내보내지 않는다.
하나의 물리 파일은 최대10만 행, 열린 끝점은최대1만 개로 제한한다. 상한 초과 시 평가를 실패시킨다.

[실행기](../scripts/audit_vpn_observation_segments.py)는 외부에서 고정한 score/manifest SHA와
동결 파일·원본·정답·예측 지문을 확인하고 전체 채점 결과를 다시 계산한다.
원본 SHA와 물리 행 번호로 사례를 대조하며 파일별 원래 수치가 정확히 재현된 경우에만 새 출력 폴더에 저장한다.
실행 전후 입력과 감사 코드 지문도 확인한다. 불일치·변조를 성공 보고서로 발행하지 않는다.

```text
python -m scripts.audit_vpn_observation_segments --directory <sealed-evaluation> --expected-score-sha256 <SHA> --expected-manifest-sha256 <SHA> --output <fresh-output>
```

로컬 검증은 연결 재사용·포트/호스트 분리·동시 시각·60초 경계·시각 역행·미상 시각·미상 끝점,
혼합 라벨의 우연한 경보·추론 오류·분모/순서/용량 및 원본/정답/예측/manifest 변조 거부를 포함한다.
Windows 관련65개·network none Linux 관련65개와 전체 Ruff+RUF100을 통과했다.
Linux 소스939파일 불변·OOM false·소유 컨테이너 제거를 확인했다.
