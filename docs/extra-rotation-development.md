# 회전 웹 로그 개발 평가 v50

2026-11-14 · `feature/chaeheeju-rotation-evaluation`, PR #60의 `165fe5e`에서 분리한 작업 폴더다.
요청된 작업 시간은 오늘 한국 시간 오전07:00 또는 원래 품질 목표 달성 중 먼저 오는 때까지다.
원래 목표는 정밀도·재현율·F1≥95%, 오탐률≤5%이며 평가 단위·지원 영역·독립성 조건을 함께 확인한다.

## 회전 파일을 지원한 이유

v49 Harrison 평가에서는 비회전 파일만 고정 문법에 포함해 VPN11,090행만 채점했다.
웹의 정확한 라벨 쌍은 `.log.1`에 있어 제외됐다. 이번에는 이미 소비한 Harrison의 웹 로그를
**개발 진단 자료**로 명시해 회전 파일 읽기를 검증한다. v49의 고정 후보·수치·노출 대장을 보존한다.
새 독립 평가 결과로 소급하지 않으며 Wilson의 원문/정답 본문은 계속 예약 상태다.

## 구현 범위

`rotation_selection.py`는 비회전 파일과 `.log.1`~`.log.9999`를 각각 별도 물리 파일로 선택한다.
같은 호스트·같은 전체 경로·같은 회전 번호의 정확한 라벨 미러만 허용한다.
형제 파일의 라벨 재사용, `.01` 같은 모호한 번호, 압축 `.gz`, 백업 접미사, 중복 이름을 허용하지 않는다.
라벨이 없으면 정상으로 만들지 않고 제외 사유를 남긴다. 파일 간 이력 병합·중복 제거는 수행하지 않는다.

`prepare_rotation_development.py`는 `observed_development` 역할과 외부 SHA를 필수로 확인한다.
ZIP/멤버/행/전체 모집단 상한, 호스트 UTC, 원본·라벨 SHA, 라벨 행 범위, 실행 전후 코드 지문을 확인한다.
입력 라벨은 그대로 유지하고 추출·예측 단계는 기존 스트리밍/고정 검출기를 재사용한다.
실패 출력은 덮어쓰지 않으며 현재 앱·PEP의 접근 권한을 바꾸지 않는다.
