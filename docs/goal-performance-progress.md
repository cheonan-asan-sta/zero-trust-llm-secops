최신 [v105 인증 개선](extra-sensitive-auth-context.md): 실제 기존 미탐3건 회수, 새FP/TP손실0. 관측 인증 P/R/F1 각각100%, FPR/FNR0%. 전체 목표 완료가 아니다.

원래6개 보안 영역의 독립 인수는 위 로그 종류8개의 합산 수치로 대신하지 않는다. 이미 분석한 R/S/F/H를 새 독립 자료로 바꾸지 않고, v104의 정책 fixture6개도 이 표에 합산하지 않는다.

다음 우선순위는 공유 감사의 현재/실행 당시 명령 근거, 웹 감사의 정상 변경 근거, VPN의 출처 내 연결/기기 관측과 기존 위험 보존이다. 공개 원본에 있는 사실만 수집한다. 공유 서버의 해당 시점 보조 journal은 원래 SERVICE_START/STOP을 반복했으며 새 명령/실행 주체를 제공하지 않았다. 사후 수집된 unit 설정 파일의 존재나 mtime만으로 과거 명령·승인 정보를 소급하지 않는다.

새 후보가 정상·위협 충돌을 해소할 수 있는지 먼저 진단하고, 새FP·기존TP손실0과 고정 모집단 비교를 확인한다. 불확실성을 숨기거나 모델에 계정명/사건ID/공격 일정 예외를 넣지 않는다. 목표를 달성할 수 없는 입력 결손은 구체적인 추가 관측 요구로 남기며 수치를 꾸미지 않는다.
