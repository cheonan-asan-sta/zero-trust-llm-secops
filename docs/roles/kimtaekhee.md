# 김택희 개인 실행 계획

천안아산역 팀 · 백엔드 데이터 테스트 담당 · 2026년 11월 1일 작성

기존 역할에 따라 FastAPI·데이터·자동 테스트·대응 엔진을 맡는다. 채희주가 전달한 정책·신뢰 경계·운영 조건을 입력·저장·상태 전이·접근 집행으로 구현하고, 상대의 인증·인프라·AI 구성을 독립 재현한다. 아래 항목은 예정 업무다.

## 1 담당 범위와 이번 주 실행

주담당은 API·입력 계약, 내구 수신·처리·중복 방지, 세션 정책 적용·회수·별도 PEP, 백업 복원 절차, 공개/합성 자료와 평가 실행기·자동 시험이다. 모델 후보·프롬프트와 인프라 신원·키·네트워크 구성은 채희주가 맡고, 구현에 필요한 계약은 함께 확인한다.

현재 기준은 v0.17.0의 로컬 모의 운영이다. 기존 177건 통과는 10/27 검증 기록이며 이번 예정 기능의 결과로 쓰지 않는다. 11/1까지 끝나지 않은 신호 권한 분리·범위 정의를 먼저 이월한다.

### 11월 2일부터 8일까지 우선 작업

1. 채희주와 인증/기기 신호별 증명 범위·정상/거부 예시를 확인하고 현재 입력·정책·시험에서 미완료인 항목을 정리한다.
2. M3·I1의 접수·저장·처리 상태와 응답 계약을 만든다. 저장 후에만 접수 성공을 반환하고 이벤트 ID·테넌트·입력 지문에 따른 중복·충돌을 정의한다.
3. 별도 처리기의 관련 세션 재평가·회수, 재시도·실패 보관·대기량 상한을 구현한다. 기존 아웃박스의 재사용 범위를 검토하고 수신 큐와 구분한다.
4. 저장 전 실패·처리 직전/직후 종료·중복·순서 역전·재시작·상한 초과를 시험한다. 정상 업무·무관 세션 유지와 회수 후 다음 접근 거부를 확인한다.
5. M7 자료·M6/C01~C10 공통 입력·기대 결과·실행/집계 틀을 준비한다. C03 두 스캐너를 같은 이미지에 처음 적용하고 원자료·검증한 발견을 기록한다.

11/8 전달물은 입력·응답·오류 예시, 저장/처리 상태와 재시작 결과, 재현 절차·시험표, 데이터/평가 계약이다. 채희주에게 보호 자원·정책·통신/키 권한표·운영 목표·모델 질문을 받아 구현과 대조한다.

공동 작업은 위협 시나리오·라벨 검토, 통합 시험, 멘토 확인 자료와 주간 보고서·인스타·최종 발표다. 개인 성과에는 실제로 수행한 변경·검토·재현만 기록한다.

SQLite를 유지할 때 쓰기 소유자·트랜잭션 경계를 고정하고 여러 프로세스의 JSONL 공유 쓰기를 피한다. 최신 회수 근거를 대조하기 전 복원된 상태에서 신규 허용을 발급하지 않는다. 필수 시험이 미달하면 새 저장소·추가 모델 등 확장 작업을 이월한다.

매주 보고서에는 문제와 멘토링 연결, 내 API·자료·시험 변경, 실제 결과와 한계, 다음 작업을 작성한다. 인스타에 사용할 결과 수치·화면·재현 조건을 제공하고 채희주가 준비한 메시지·구조도와 대조한다. 발표·보고서 최종 검토는 공동으로 수행한다.

완료 기록에는 작업 ID(M/I/C)·날짜·변경 파일/버전·재현 방법·기대/실제 결과·상대 검증자·남은 결함을 남긴다. 도구 비교는 같은 입력·설정 조건과 반복/관측 구간, 안전·자원·오류 원자료를 보존한다. 채희주의 선정 초안을 원자료와 대조하고 독립 재현한다. 문서 조사와 실측을 구분하며 데이터 출처·라벨·세션 분리도 유지한다.

기능·장애 시험은 로컬 Docker Compose와 규칙·모의 응답으로 수행한다. 실제 모델 평가에는 합의한 한도를 별도 적용하고 모의 결과와 구분한다. AWS 생성·배포, GitHub 업로드와 실계정 변경은 수행하지 않는다. 비밀값·실사용자 식별정보를 시험 자료와 화면에 남기지 않는다.
