# 정상 웹 요청을 보강한 탐지 모델 비교

2026년 11월 26일 · `extra` · 로컬 CPU 실험

## 모델과 평가 분리

FPAD 발행자 학습 파일 37,779건으로 ExtraTrees 모델을 만들었다. URL과 저장 본문의 길이, 문자 종류·빈도 등 고정된 구조 특징만 입력했다. 정상 12,887건을 추가한 후보는 동일 요청을 묶고 서로 다른 라벨이 붙은 학습 그룹을 제외해 46,164개 고유 그룹으로 학습했다. 두 모델의 경보 기준은 미리 고정한 0.95였다. 쿠키·호스트·사용자·응답·발행자 라벨과 위치 주석은 예측 입력에 쓰지 않았다. [발행자 학습·평가 자료](https://github.com/Sec-AI-research/WebSpotter) · [추가 정상 웹 자료](extra-public-legitimate-web-20261126.md)

발행자 학습 파일만 사용한 최초 후보를 기존 CRS와 합치면 FPAD F1은 99.26%였다. 같은 후보에서 CRS 판단을 빼고 모델만 적용했을 때, 별도 웹 정상 표본 12,887건의 오탐률은 73.75%였다. FPAD 결과가 높은 모델도 다른 정상 웹 요청에는 전이되지 않는다는 근거다. 이 정상 표본은 이후 후보의 개발 입력으로만 사용했다. [최초 후보 집계](infrastructure-results/public-web-shape-before-normal-augmentation-20261126.json)

후속 정상 평가의 15,250건은 앞선 개발 파일과 수집 사이트 그룹이 겹치지 않는 12개 파일에서 가져왔다. 그중 학습 자료와 URL 및 본문이 정확히 일치한 198건을 두 모델 비교에서 똑같이 제외해 15,052건을 채점했다. 실제 기록된 Host가 개발 표본에 한 번도 없었던 12,316건도 따로 집계했다. Host는 이 집단을 구분하는 데만 사용했다. FPAD와 FPAD-OOD는 이전 CRS 비교에서 이미 본 자료이고 이번 모델 학습에는 발행자 학습 파일만 사용했다.

보강 모델과 CRS의 조합은 FPAD에서 95%·5% 수치에 들었다. FPAD-OOD에는 정상 라벨이 없어 재현율만 보고하며, 95%에는 못 미쳤다. 또한 최초 형태 모델이 탐지했던 위협 중 FPAD 233건, FPAD-OOD 1,302건을 놓쳤다. 전체 기준 충족과 운영 채택은 보류한다. [최종 고정 기준 결과와 봉인](infrastructure-results/public-web-shape-crs-transfer-20261126.json)

## 재현

Python 3.12와 scikit-learn 1.7.2를 사용했다. 세 비교 자료의 고정 CRS 예측을 지정하면 이들을 합친 행별 비교도 실행한다. 예측을 먼저 봉인하고 이전 코드로 재실행한 예측 지문과 대조했다. AWS와 유료 API 호출은 없었다.

```powershell
python -m scripts.evaluate_public_web_shape_transfer <FPAD-파일-폴더> <정상-개발-폴더> <정상-추가-평가-폴더> <새-출력> --crs <FPAD-CRS-봉인> <FPAD-OOD-CRS-봉인> <정상-추가-CRS-봉인>
```
