## 감사 전에 고정한 조건

[메타데이터 계약](../infra/f1-lab/rba-metadata-protocol.json)은 실제 ZIP/CSV 크기·해시·CRC·헤더와
첫128개 probe receipt 해시를 고정한다. 그 후 전체 CSV를 메타데이터 목적으로만 기계적으로 읽는다.
개별 사례의 입력/라벨을 설명 자료로 출력하거나 모델에 전달하지 않는다.

사용자 문자열은 `rba-user:` 네임스페이스의 SHA256으로 바꾼다.
이미 관찰한81명은 이후의 모든 행을 개발로 배정한다. 다른 사용자는 해시 앞8바이트의 정수값을100으로 나눈 나머지로
0~69 개발,70~84 보정,85~99 예약 후보에 배정한다. 라벨·클래스 지지·모델 결과에 맞춰 다시 고르지 않는다.
사용자를 해석할 수 없으면 `unassigned`에 남기며 IP/전역 사용자로 대체하지 않는다.

이는 **사용자 분할 후보**다. 실제 기기·요청 템플릿·정확한 이벤트 중복·미래 시점 분리를 인증하지 않는다.
예약 후보의 클래스 지지는 확인할 수 있지만 그 조건부 관측/라벨 교차표는 모델 선택 자료로 열지 않는다.
기계적 원자료와 사용자 해시별 집계 DB는 runtime에 두고, 전달 자료에는 필요한 지지/구조 집계만 사용한다.

## 검사 대상과 자원 경계

- 로그인 성공·공격 IP·확인된 ATO의 세 boolean을 각각 집계한다. 미확정을 false/정상으로 바꾸지 않는다.
- ATO=false가 여섯 영역 전체의 정상 정답은 아니다. 이진 평가 정답 계약은 아직 선정하지 않았다.
- 행 구조가 맞지 않으면 `unassigned`·미확정으로 수를 보존한다. CSV 해석/CRC 오류는 부분 결과를 완료로 게시하지 않는다.
- 시간대 없는 시각은 그대로 구분한다. 시간대가 있는 시각만 명시된 오프셋으로 UTC 정규화한다.
  입력 순서 역전·형식·분할별 범위는 품질 메타데이터이며 정상/악성 판단에 쓰지 않는다.
- 빈 RTT와 유효 범위 밖 값을 구분한다. 누락을0으로 채우거나 해당 행을 빼지 않는다.
- CSV는 통째로 파일에 풀지 않는다. 최대16GiB·4천만 기록·물리 행/필드64KiB·실행3600초를 제한한다.
  SQLite는 사용자 해시/분할/행·라벨 수만 저장하며 최대1GiB·캐시16MiB·메모리 배치25,000행이다.
- 전체 EOF·정확한 비압축 바이트 수·표준 ZIP CRC 검사와 ZIP SHA256 전후 일치가 확인되어야 전체 검사가 완료된다.
  첫128개 probe의 CRC 미검증 기록을 이 후속 결과로 소급 변경하지 않는다.

진행 중에는 `metadata.sqlite3.part`와 progress만 생긴다. 성공한 경우에만 DB를 완료 이름으로 게시하고
`audit.json`의 `completed=true`를 기록한다. 실패/진행 중의 집계를 전체 모집단 결과로 쓰지 않는다.

## 통제 입력 검증과 실제 실행

관련 Windows244개·격리 Linux244개가 통과했다. 라벨을 바꿔도 사용자 분할은 같고,
관찰 사용자 전체가 개발로 남는지, 알려진/미확정 라벨과 구조 오류 행이 모두 집계되는지 확인했다.
CRC 변조·행 수 제한·probe 지문 변경은 완료/최종 DB 게시를 거부한다.
원시 사례 문자열이 결과/메타데이터 DB에 저장되지 않는지 검사했다.

첫 집중 실행은7통과/1실패였다. 라벨을 뒤집어도 개발 집계의 음성 수가 달라져야 한다는 시험 가정이
균형 표본에서 성립하지 않았다. 사용자별 라벨 변화와 분할 불변을 직접 대조하도록 시험을 수정했다.
이전 XML은 보존한다. 초기 구문 검사 오류도 실제 자료 실행 전에 보완했다.
최종 Linux450파일의 실행 전후 소스 지문·시험 컨테이너0을 확인했다.

v30 중간 기록에서는 세션94763·PID8660이 실행 중이었고 전체 클래스 수·CRC·완료 DB가 미확정이었다.
그 뒤 같은 소스/계약을 유지한 채 exit0을 확인했다. 관측 timeout으로 중복 실행하지 않았다.
완료된 세션을 다시 poll/재시작하지 않는다. 원래 중간 기록은 실패/진행 이력을 보존하기 위해 수정하지 않는다.

[v30 실행 근거](infrastructure-results/extra-rba-metadata-v30-20261112.json)는 검사 결과와 실제 실행 중간 상태를 구분한다.
원본 앱·기존 라벨 유지, 예약 AIT/CloudTrail 최종 본문 미열람, AWS·유료 API·GitHub 업로드0이다.
기존 여섯 영역의 새 독립 평가와 P/R/F1 각각95%·FPR5% 이하 목표는 계속 미완료다.

다음은 출처별 정답이 원래 여섯 영역의 어떤 판단을 검증할 수 있는지 확정하고,
그 범위 안에서 관측 특징·주체/시간/중복 경계를 검증하는 것이다. ATO 연구만으로 목표를 완료하거나
실제 기기 건강·소유자 정책·업무 승인을 추정해 넣지 않는다. 완료 대조는 코드 변경 없이 수행했으며
