# 공개 성공 POST 전이 시험과 본문 보강 비교

2026-11-23 · `extra` · CPU 로컬 평가 · AWS 및 유료 LLM 호출 0회.

## 새 평가 자료

SR-BH 2020 원본의 발행자 MD5 `173ec515308bdce5aec19cfd5b792596`와 다운로드 SHA-256 `9c73c90ce6564ae48b14f7179cd864d037a6a130ef69c68c1626ec5d7ce4a910`를 확인했다. 메서드가 POST이고 응답이 2xx인 행을 라벨 없이 사전 선택했다. 실제 채점 대상은 **정상 1,838건, 위협 17,715건**, 총 19,553건이다. 저장된 요청 본문이 있는 행은 19,553건이고 정답이 모호한 선택 행과 선택 행의 추론 오류는 각각 0건이다. 실서비스의 공격 기저율을 대표하지 않으며 다른 메서드나 리다이렉트의 성능은 이 집계에 포함하지 않는다. [발행자 자료](https://doi.org/10.7910/DVN/OGOIXX) · [데이터 연구](https://doi.org/10.1016/j.cose.2022.102788)

기존 웹 모델과 성공 POST 보정은 다시 훈련하지 않았다. 원본의 시각·클라이언트로 인과 HTTP 이력을 구성하고 원래 기준과 보정안을 예측한 뒤 예측 SHA를 고정해 채점했다. 이 첫 비교에서 본문은 읽을 수 있는지 집계했으며 판정 특징으로 사용하지 않았다. 발행자의 정상 열과 위협 열이 함께 표시됐거나 둘 다 표시되지 않은 경우는 미확정으로 다루고 그 수를 보고한다.

Apache 자료에서 관찰한 보정 효과는 새 자료에서 위협 탐지를 유지하지 못했다. 기존 POST 보정은 운영 적용을 보류한다. Coraza 3.8.1과 고정 OWASP CRS 4.25.0을 로컬 라이브러리로 호출해 데이터의 요청 대상·헤더·본문을 분석했다. 저장된 본문으로 Content-Length를 계산했고, 원본 네트워크로 요청을 전송하거나 접근 권한을 바꾸지 않았다. 공개 원본의 라벨은 ModSecurity 결과를 사람과 절차가 검토한 것이어서 CRS 계열 규칙과 평가 근거가 일부 연관될 수 있다. CRS의 보조 경보는 기존 탐지 손실과 새 오탐 없이 미탐을 68건 회복했으며 기존 오탐 부담은 그대로였다. [Coraza의 OWASP CRS 연동](https://www.coraza.io/docs/tutorials/coreruleset/)

## 본문 구조 모델의 시점 분리 실험

같은 공개 자료에서 7월 17일을 학습, 18일을 보정, 19일을 시점 검증으로 지정했다. 같은 요청 대상과 본문이 뒤 구간에 있으면 앞 구간에서 제외했다. 학습·보정·시점 검증 분모는 각각 5,088, 13,007, 525건이다. 원문 값·IP·절대 시각·정답을 모델 특징에서 제외하고 요청 대상·본문의 길이와 문자 구조, 응답 코드만 사용했다.

| 시점 검증 525건 | 정밀도 | 재현율 | F1 | 오탐률 | 오탐 / 미탐 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 웹 모델 | 72.26% | 73.51% | 72.88% | 94.21% | 114 / 107 |
| 구조 모델 | 95.55% | 90.35% | 92.88% | 14.05% | 17 / 39 |

보정 구간에서 네 목표와 기존 탐지 보존 조건을 함께 만족하는 후보가 없어 진단용 기준의 수치만 보고했다. 시점 검증에서는 새 오탐 1건, 기존 탐지 손실 39건이 있었다. 미탐 총계가 줄어도 기존 탐지 손실이 따로 발생할 수 있어 두 수치를 분리했다. 이 비교는 같은 출처의 구간 분리 실험이며 다른 출처에서의 독립 최종 성능은 미측정이다.

## 재현

- [성공 POST 평가기](../scripts/evaluate_public_successful_post.py)는 공식 CSV를 로컬에서 읽는다. 먼저 `python -m scripts.evaluate_public_successful_post <csv> <new-output>`으로 예측을 저장하고, 같은 명령에 `--score-seal <seal.json의 SHA-256>`을 붙여 채점한다.
- [CRS 비교기](../scripts/evaluate_public_post_crs.py)는 [고정 Go 프로그램](../scripts/experiments/crs_shadow/main.go)을 실행한다. 해당 모듈 디렉터리에서 `go build -trimpath -o crs-shadow.exe .`로 빌드한 뒤 `python -m scripts.evaluate_public_post_crs <csv> <post-output> <crs-output> --exe <binary>`로 예측을 저장한다. 같은 명령에서 `--exe <binary>`를 `--score-seal <CRS seal.json의 SHA-256>`으로 바꾸면 채점한다.
- [요청 구조 비교기](../scripts/evaluate_public_post_body_shape.py)는 `scikit-learn==1.7.2`에서 `python -m scripts.evaluate_public_post_body_shape <csv> <post-output> <new-output>`으로 실행한다. 보정 점수로 기준을 정한 뒤 시점 검증 예측을 봉인하고 정답을 결합한다.

기존 관련 테스트 142개, 발행자 라벨 분리와 본문 제외를 확인한 새 테스트 1개를 통과했다. [결과와 SHA-256](infrastructure-results/public-successful-post-transfer-20261123.json)에 감사를 위한 집계를 남겼다. 판정 경로·자동 대응 정책의 운영 적용은 아직 승인 조건을 충족하지 않았다.
