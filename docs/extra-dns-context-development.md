# DNS 질의 문맥 개발 비교 — v56

2026-11-14 · 기존 R/S/F 개발 자료의 잔여 미탐2,640행 중2,595행이 DNS 로그에 있어,
질의 종류와 같은 원시 클라이언트의 엄격한 과거 질의 문맥을 추가했다.
**전체 비교는 완료했지만 새 오탐96건이 발생해 후보를 채택하지 않았다.**
Wilson용 v53 고정 코드와 별도 작업 폴더에서 개발했고 해당 후보를 변경하지 않았다.

## 추가 관측과 경계

- dnsmasq 전용 로그와 호스트 이름이 있는 syslog의 정확한 문법을 구분해 처리한다.
- A/AAAA/PTR/TXT 등 고정 질의 종류, 역방향 이름 여부, 응답 종류·로컬 응답 여부를 관측한다.
- 같은 물리 파일·resolver 프로세스·명시 클라이언트에서 이전1/10/60초의 질의 수,
  서로 다른 이름/질의 종류 수와 역방향 질의 수를 계산한다.
- 현재 행과 같은 시각의 모든 질의는 과거 문맥에서 제외한다. 원본 순서에서 시각이 역행하거나
  resolver 프로세스/호스트가 바뀌면 과거 상태를 초기화한다.
- IP·도메인 이름·호스트 이름·PID·절대 시각·원본명·행 번호·정답 문자열을 학습값으로 내보내지 않는다.
  주소/이름의 내부 지문은 문맥 연결 키일 뿐 사용자·기기 인증이나 업무 권한 근거가 아니다.
- 응답/forwarded 행에는 요청자 IP가 없으므로 이름만으로 이전 질의의 사용자를 차용하지 않는다.
  시각이나 문법을 모르면 해당 문맥을 미확인으로 둔다.
- 기존 경보는 유지하고 새 후보 점수가0.95 이상인 확인된 DNS 문법 행에서만 보조 경보를 추가한다.
  접근 허용·차단·권한 회수를 실행하지 않는다. 추론 실패도 평가 분모에 남긴다.

[dns_context.py](../scripts/f1_lab/dns_context.py)는 관측만 계산한다.
기존 모델의 특징 계약을 바꾸지 않고 `raw-dns-query-context-5`라는 별도 선택형 프로필을 추가했다.
[개발 실행기](../scripts/run_dns_context_development.py)는 원시/준비/이전 예측 SHA와 사례 순서를 대조한다.
특징 추출기는 정답 파일을 읽지 않는다. 원래 DNS 전체 행을 유지하며 미파싱 행을 삭제하지 않는다.

## 학습·비교 계획

Russell 자료 하나로 깊이8·최소 leaf5·class balancing 없음의 이진 트리를 학습한다.
설정과 경보 기준0.95를 실행 전에 기록한다. 트리 점수는 경험적 비율이며 보정된 운영 확률은 아니다.
기존 모델3종과 웹·VPN 후보, 원시 정답은 바꾸지 않는다.

Russell의 재생은 학습 자료 평가이며 Santos/Fox도 이전부터 관찰한 개발 비교 자료다.
각 비교 예측을 기록한 후 정답 subset을 연결한다. 새 미관측 독립 평가로 부르지 않는다.
모든 개발 자료에서 새 FP0·기존 TP 손실0·추론 오류0이며 새 TP가 있어야 개발 후보 조건을 통과한다.
이 조건을 통과해도 원래 여섯 영역의 독립 최종 목표를 달성했다는 뜻은 아니다.

## 검증과 실패 보존

Windows 관련37개·network none Linux 관련127개와 전체 Ruff+RUF100이 통과했다.
실제 파일 추출 경로에서도 syslog/전용 로그 두 형식, 원시 행 지문·순서,
정답 미접근, 같은 시각 격리, 시각 역행·만료·다른 호스트/프로세스, IPv6,
응답의 미상 요청자, 기존 경보 유지·추론 실패 분모·변조 거부를 확인했다.
Linux 스냅샷933파일 불변과 해당 소유 컨테이너 제거도 확인했다.

첫 실행은 실제 파일에 호스트 토큰이 없어 새 문법 관측0행이었다.
Russell275,900행의 이 상태를 확인한 뒤 해당 실행만 중단하고 부분 출력/중단 이유를 보존했다.
이를 새 특징이 검증된 성능 결과나 미탐 감소 실패의 확정 근거로 사용하지 않는다.
두 정확한 형식을 지원하도록 보완했고, 유효 문법과 질의 문맥이 하나도 없으면 학습 전에 실패하도록 했다.
수정 후 실제 첫1,000행에서 문법835행·명시 질의335행을 확인하고 새 출력 폴더로 비교를 재개했다.

완료된 재실행 위치는 `runtime/f1/dns-context-development-v56-20261114-02`이고
첫 실패는 접미사`-02`가 없는 폴더에 그대로 있다. 유료 LLM·AWS 호출은0이다.
