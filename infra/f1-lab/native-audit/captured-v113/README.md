# Controlled native audit training capture

169 complete physical audit records from eight real authorized SSH/sudo log-read sessions in an exclusively owned Ubuntu QEMU guest. The outer container network was disconnected before collection; audit lost=0, guest and container exited. Source bytes and the ASCII GS enrichment suffix are retained unchanged.

All labels describe this predeclared normal-only controlled training protocol. They are not independently adjudicated incidents or a final performance benchmark, and must not be added to the original evaluation denominator. Native actor fields remain observations, not identity or authorization grants. No client private key or guest disk image is included. The guest host keys remain local test credentials in a private runtime overlay.

The original [execution receipt](execution.json) and byte-exact source can be re-ingested with `scripts.prepare_native_audit_training`. Validate the receipt SHA-256 before intake. This receipt is recorded by the local collector/controller, not a hardware attestation or independent human review.
